# 视觉资产策略 —— 图片 / Logo / 截图的优先级瀑布

> 规范层。定义页面图片资产的四级优先级与硬禁令。"极简站也需要 2-3 张真图"——纯文字排版页面是 AI 产出 uninspired 的头号信号之一。

## 图片来源四级优先级（从上到下取，级级降级须留痕）

| 级 | 来源 | 适用 | 注意 |
| --- | --- | --- | --- |
| 1 | **图像生成工具**（ip 子命令 / text_to_image API） | 有明确情绪与主题要求的场合 | prompt 写主题不写"abstract tech background" |
| 2 | **带语义 seed 的 picsum**（`https://picsum.photos/seed/<语义词>/<w>/<h>`） | 快速原型、占位 | seed 用语义词（`seed/forest-lab/800/600`），禁 `?random` |
| 3 | **真实来源图**（用户素材 / 官方 asset / 已授权图库） | 品牌页、证言、Logo 墙 | 记录来源；禁止热链未授权 CDN |
| 3b | **开放图库检索**（Openverse / Wikimedia Commons / Art Institute of Chicago / Met 开放接口） | 需要"主体的世界"的真实素材：老明信片、旧地图、材料特写、行业版画、同类馆藏 | 免 key；许可默认仅取 CC0 / PD / BY / BY-SA（NC/ND 出局）；**下载到本地用，禁热链**；CC BY/BY-SA 按档案原文写署名与许可链（`--credits`） |
| 4 | **显式占位槽**：输出 `<img>` 槽 + 尺寸/比例/内容说明，并告知用户"待替换" | 无法安全取图时 | 禁止静默留空或用灰色 div 顶替 |

## 开放图库诚实细则

- **found 图永非客户自有**：可以展示"主体的世界"（行业/年代/材质语境），不可冒充其产品、空间或团队——冒充即造假
- **caption 按档案原文写**：馆藏名/作者/年代照录，不润色不改写
- **CC BY-SA 衍生图同许可**传承；检索词写"主体的世界"（老明信片/旧地图/材料特写），不写"generic landscape"

## 硬禁令

1. **禁止 div 拼假截图**——用嵌套 div/渐变/文字模拟"产品截图"是头号 AI 破绽。要么用真实截图素材，要么出占位槽 + 说明。
2. **禁止 `?random` 随机图**——每次渲染都换图，preview 不可复现。
3. **Logo 墙必须真 SVG**：优先 Simple Icons / devicon 官方源；虚构品牌则配自造 SVG 字标（几何标记即可，禁止文字假装 logo）。
4. **具名品牌资产获取协议**：设计中要点名/并列展示的真实产品，必须取官方 logo——清单里有一个没取到 = STOP 补齐。四级兜底链（逐级降级，每级下载后用 `file` + `head -c 90` 核对真伪，防 CSS 剪影/空壳）：svgl API → Simple Icons（按品牌色上色）→ 官网 HTML grep inline SVG → Google favicon sz=256。配套「5-10-2-8」铁律（≤5 个 logo / 10 秒可辨 / 2 种来源交叉 / 8 分识别度）。反例存档：Kimi 用近色 #1783FF 冒充、DJI Pocket 用 CSS 剪影、五大 Coding Agent PPT 五个 logo 全未取。
4. **LOGO-ONLY 规则**：Logo 墙下方禁止配"Trusted by 1000+ teams"式品类说明文字凑数。

## 素材边界与可判定口径

> 先划边界再取图,先定口径再验收。

### 代码实现 vs 独立素材

| 走代码实现 | 走独立素材 |
| --- | --- |
| 布局 / 栅格 / 容器;文字与文字效果;控件;普通线性图标;动态图表(SVG / Canvas);几何装饰、渐变、边框、阴影 | 摄影照片;原创插画;品牌视觉符号(需授权的 logo 原稿);3D / 玻璃质感 / 复杂纹理的成品视觉 |

- 判据一句话:**"一个胜任的前端用 HTML/CSS/SVG 原语和现成字体,能否在不用任何图片文件的情况下重建它?"** 能 → 代码;不能 → 素材;容器是代码但内含必须用图的部件 → 混合(容器走代码,图走素材)
- 图片放入明确容器(尺寸 / 比例 / 裁切声明);正文、数据标签与操作保持可编辑文本——**禁止把文字烙进图片**
- 优先复用质量足够的原始素材 / 项目资源 / 干净裁图;缺失或不合格才生成或重绘,**不默认重画品牌标识**(品牌标识缺原稿且任务已授权重建时才按实际 Logo 参考锁定轮廓与图文比例,不重新设计品牌)

### 可判定口径

| 判据 | 口径 |
| --- | --- |
| 有效像素 | 素材有效像素必须覆盖最终显示需求:**150 CSS px 显示宽 @DPR2 → 至少 300 有效像素宽**;**大面积留白不算图形分辨率** |
| 放大 | 插值放大不恢复细节——"放大后够大"不等于够清晰 |
| 矢量声明 | 生成 PNG、或 SVG 里包裹位图,都**不得冒称原始矢量文件**;品牌标识优先原始 SVG 或高清原稿 |
| 容器不合 | 尺寸或构图不适合容器时**回规格改**(重定比例 / 裁切余量 / 换图),不靠反复移动或拉伸图片修补 |
| 透明度 | 需要透明时只用实际接口支持的真 alpha;PNG 扩展名 / RGBA 模式 / 画入的棋盘格都不能证明透明(防御写法与验收口径见 [`../commands/ip.md`](../commands/ip.md) 交付形态节) |

### object / photo 的诚实占位

> 与 [`../dimensions/hero-stage.md`](../dimensions/hero-stage.md) 的 subject 分类配套:抽象物诚实渲染,实物与照片诚实占位——不做半成品 CSS 模拟。

- **object(实物产品 / 3D 硬件)**:不硬画 CSS 写实——用**通用暖金属形占位**(竖向药丸 / 横向圆盘 / 软胶囊),把舞台做完整(顶光 / 暗角 / 地面接触阴影 / 竖向反射),占位形本身是设计语言的一部分,页面在换真图前即可交付;上生产前换成品牌真实渲染图或产品摄影,并在交付说明注明
- **photo(真实照片位)**:无法真渲染时用**带说明的诚实地占位**(中性渐变底 + 一句话描述这张图实际应拍什么),不假装成一张真照片、不用假 stock 图冒称实拍;出处口径同「取图诚实检查」

## 头像与插画（真实性与授权）


- **头像必须真实照片**：证言 / 团队 / 背书场景的头像一律使用真实照片（用户提供或已授权素材）；禁止首字母块、插画头像、无脸剪影顶替。
- **禁止生成人像冒充真实背书**：生成人像只能用于显式虚构场景并随产物标注；不得呈现为真实客户 / 员工 / 背书者。措辞联动：无可验证证据不得描述为"获奖 / 认可"（见 [`ai-tells.md`](ai-tells.md) 第 4 节）。
- **插画禁模型手绘拼凑**：不得用模型手写 SVG / CSS / canvas 路径拼"插画"；插画走图像生成工具或授权素材（上文四级优先级 1 / 3）。例外：品牌标记、界面图标、数据图表（分别走 [`../dimensions/icon.md`](../dimensions/icon.md) 与 [`vocabulary/galleries.md`](../vocabulary/galleries.md) 的既有规范）。
- 本节为 [`../templates/landing-patterns.md`](../templates/landing-patterns.md) L02"证言带真实头像"与 Testimonial"身份可溯"筛选标准提供规则支撑。

## 数量基线

| 页面模式（surface-modes） | 真图基线 |
| --- | --- |
| Experience / Persuade | ≥ 4 张（常态 6-12；首屏至少 1 张主视觉）——114 站实测弱站的共同点正是图少，评委把"图不够"记为 fault |

**密度天花板(与下限成对)**:首屏之下照片 ≤1/3 页面(摄影主导/作品集形 ≤45%);禁两节连排照片主导;产品截图不计入配额。

**图片删除测试**:拿掉这张图,页面丢一个事实才留——纯氛围图/城市夜景/办公桌照出局。

**文字压图 scrim 配方**:scrim 取墨色 35-65% 渐变、只垫文字侧;文字对图 ≥4.5:1;文字落图最平静处;禁居中白字压繁图。

**生产资产双检**:栅格 ≥1.5× 区域分辨率;透明资产在亮/暗双底各合成检验一次(白漆实心/内洞透空/细边无晕)。
| Operate | 0-1 张（图标即可，不强求） |
| Read | 0-2 张（配图须承载信息） |

## 生成图 prompt 配方(七段按序)

1. **主体**:一句话,具体且物理("雾中礁石海岸上的小灯塔,光束探入雾里")
2. **场景**:它在哪,保持简单
3. **光与色板**:匹配页面——**写明页面背景色让边缘可融合**,写光的方向
4. **风格**:一个明确方向(电影感静物/柔和 3D/版画/绘制背景),选贴产品的,不选流行的
5. **构图**:主体在哪一侧给文字留白;"作为整个 hero 背景"要 16:9 或更宽、**下五分之一保持安静**(产品视图从底边升起)
6. **排除**:no text, no letters, no logos, no UI, no watermark
7. **格式**:按槽位比例、2 倍显示尺寸导出(WebP/AVIF)

一次生成,按那句话与色板评审后**改 prompt** 而不是重摇;存进项目 assets,不留临时 URL。无法生成时留**纯表面空槽**(精确尺寸+布局圆角,**槽内无文字**),prompt 写进报告不写上页面。背景移除陷阱:深色对象(熄屏的黑色屏幕)会被连同背景切掉——要求屏幕用对比平色,或从外缘重建 alpha。

## 图像融合与一致性

- **边缘必须融入页面**:硬矩形边缘压在不同色的页面上即 slop;不匹配时 mask 渐隐(`mask-image: radial-gradient(closest-side, #000 70%, transparent)`)或页面色渐变罩
- **同一视觉内数据一致**:列表显示 INV-0142 某客户,手机模型里就得是同一客户、同一单号、同一金额
- **图内禁字**:文字/假按钮/假 logo 烤进图里 = 立即翻车,文字永远用真 HTML

## 图像代码处理(四技法,只用于主视觉且贴人格)

把生成图变成"为这页而做"的代码处理,选一,不当装饰铺开:**glyph 字符画**(亮度选字符,字符来自产品材料——金融用 `.:17408$%`、代码用 `.:/{}<>#`、音乐用音名,cell 6-10px 用 mono);**halftone**(点阵随亮度变径,单 ink,贴编辑/印刷人格);**dither**(两三色抖化,贴复古/技术人格,加载时做一次);**duotone**(亮度映射到 ramp 最深表面+accent 两色,`mix-blend-mode: color` 或 feColorMatrix——让任何生成图归入色板的最简法)。性能:像素只读一次(禁在动画循环里 getImageData)、glyph atlas 预烘焙、8-12 步/秒非 60、离屏暂停、DPR 上限 2。

## 视频/动图规范

- **poster 必备**：`<video poster>` 帧与视频首帧一致——实测仅 31% 的站点有 poster,评委把缺失记为 fault;加载慢时白屏一闪即 AI 稿感
- **一屏一动态图**：两个自动播放的动图同屏互相抵消
- **规格**：5-15s、<5-10MB、循环无跳帧(首尾帧相接)
- **对比度逐帧检查**：文字压在视频上时,视频的每一帧都是背景——只查 poster 不够,抽查中段帧
- **reduced-motion 显示 poster**;进入视口才播(`IntersectionObserver`),离开视口暂停

## 空态插画策略

> 落地 [`vocabulary/states.md`](../vocabulary/states.md) 的空态模式引用；取图来源仍走上文四级优先级。

- **首用空态**（states.md 的 `state-empty-first-use` / `state-empty-starter`）：可用插画或示例数据传达"这里将出现什么"，插画承载正向情绪引导。
- **无结果空态**（`state-empty-no-results` / `state-empty-clear-filters`）：优先**文字 + 筛选调整建议**，而非插画——用户要的是出路不是装饰；确需配图时从简。
- **错误态**（`state-error-*` / `state-offline`）：**禁装饰插画**；仅允许功能性示意（断网/锁形图标），重心放在重试动作与已保留数据。

## 取图诚实检查（诚实能力声明）

> 在 Design Read / 交付说明中**点名任何取图路径之前**执行。

- **先查本会话真实工具清单**：确实存在图像生成工具 / MCP 图像工具 / 网络抓取，才能宣称对应路径。**listed ≠ usable**——清单里有但无凭据的生成器不是可用路径 A，只是名字。
- **证明再承诺**：准备走的路径，先验证它真的能跑（工具存在、凭据有效、网络可达），再写进 `Images:` 说明；验证失败的按降级处理并留痕。
- **不基于自己的推断代用户取图**：`Images:` 行（每个图槽的内容与来源）随 Design Read 一并给出、等用户确认；不在确认前生成或下载。
- 每个图槽都给出**来源 + 槽位语义**（这里放什么、从哪来），禁止"稍后配图"式含糊。
