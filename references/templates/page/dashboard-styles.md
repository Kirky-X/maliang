# Dashboard 风格集（Dashboard Styles）

## 一句话定位
一文件四种 Dashboard 气质——每种 = 结构组件 + 配色策略 + 层级手法的组合公式，共享 v08 的配色占比公式与"三问自查"底线；换公式即换气质，替代"紫渐变 + 四张等大 KPI 卡"的模板脸。

## 视觉特征（通用法则 + 四风格 token，v08 数值）
- 三问自查（动手前先过一遍）：重色落在哪 / 第一屏给了谁 / 衰减了什么
- 配色占比公式：底色 50-95% · 主色/强调色 ≤5% · 彩色 1-2%；重色永远只给一处当前态或一块区域
- 大色块分区 ≤4 块，超过即调色盘；深底灰阶三档只差十几点（读数 L7/L12/L18/L30）
- 密而不乱 = 同一套圆角 + 卡与卡之间那点留白；一张卡复制四遍只改一行，页面才安静

### 风格一：极简商务（Minimal Business）
- 结构组件：顶部导航 + 数据卡片 + 趋势图表 + 结构化列表
- 配色策略：浅底近白 + 墨色文字 + 唯一强调色；底色禁纯白，改奶油/暖白
- 层级手法：留白与间距 + 卡片层级；最重指标独占一整行（结构占比可至 64%）
- 适用：企业数据后台。案例：Switchyard 门店运营台（6.4h 营业 / 02:35 环形计时 / 开机检查 2/8）

### 风格二：清爽轻量（Light & Airy）
- 结构组件：三栏留白 + 大圆角卡片 + 红黄绿刻度条 + 日历宫格
- 配色策略：浅色底 + 单一高亮色（"整页只留一个高亮色"）
- 层级手法：大圆角卡·四级信息层级；密而不挤靠留白和统一圆角
- 适用：个人工具/学习/记录类。案例：练习量表（评分 811 优秀，刻度 300/630/690/1000）

### 风格三：暗黑科技（Dark Tech）
- 结构组件：图标侧栏 + 圆形数据徽章 + 动态网格 + AI 助手卡
- 配色策略：深色底 95% + 全部彩色 1.4% + 三档灰 3%（灰阶 L7-L30，只差十几点）
- 层级手法：搜索横贯整屏定第一屏；五张指标一字排开；高对比数据点亮深底
- 适用：AI 监控台/实时运营。案例：The Daily Grind NY（THROUGHPUT 9,428 / 容量徽章 78-91%）

### 风格四：高饱和撞色（Bold Contrast）
- 结构组件：超大标题压版面 + 圆头色块图表 + 进度胶囊 + 推广卡
- 配色策略：荧光 × 纯黑，只亮一个颜色，其余全部收成黑白（近白 80% / 墨黑 12% / 荧光 5.8%）
- 层级手法：圆头胶囊图表替默认柱状高亮当前值；撞色不等于花
- 适用：作品集/创意团队/自动化工具后台。案例：Operations 780/1,000 荧光黄胶囊 82%

## 结构骨架
1. 导航定调：图标侧栏 = 暗黑科技；顶部导航 = 极简商务/清爽轻量
2. 第一屏只给一个主角：最重指标独占整行或超大主卡（约 25% 屏面，主次差 4 倍级）
3. 次级指标按同圆角卡片阵列，分隔线能省则省（少一条线就像一本杂志）；助手卡/推广卡等"语气件"放末位（一行斜体即可换语气）

## 适用场景 / 慎用场景
- 适用：企业后台、监控台、工作流、个人工具，按风格对号入座
- 慎用：内容为王的页面（彩色压到 1-2% 会饿死内容）；纯白底上做浮起胶囊导航（浮不起来）

## AI 常见翻车点（反模式）
1. 只对 AI 说"做一个高级 Dashboard"——无效提示词，产出像模板（v14 红线划掉的反例）
2. 大色块超过 4 块，分区沦为调色盘；重色出现第二处，页面失去重心
3. 底色一花，半透卡上的字开始飘；彩色在深底上多一点就脏
4. 紫色渐变 + 发光折线 + 四张等大 KPI 卡 + Welcome 问候 = AI 默认输出

## CSS 关键实现（≤15 行）
```css
.dash { display: grid; grid-template-columns: 64px 1fr; min-height: 100vh; } /* 图标侧栏 */
.kpi-hero { grid-column: 1 / -1; } /* 最重指标独占整行 */
.cards { display: grid; grid-template-columns: repeat(auto-fit, minmax(240px, 1fr)); gap: 12px; }
.card { border-radius: 22px; padding: 16px 20px; background: var(--surface); } /* 全页统一圆角 */
.dark { background: #17181c; --g1: #1d1e23; --g2: #26282e; --g3: #34373f; } /* 灰阶差十几点 */
.pill { border-radius: 999px; background: var(--hl); } /* 圆头胶囊图表；强调色全页只一处当前态 */
```
