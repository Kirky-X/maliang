# AI 工作台 / Agent 控制台（AI Console）

> 整页模式（page-pattern），叠加在 Operate 模式（[`../../meta/surface-modes.md`](../../meta/surface-modes.md)）之上使用。适用判定：**页面上有"不是用户、而是别的东西在持续干活"**——agent/智能体多步执行、队列、流式输出、中途可失败。纯聊天机器人（无工具/队列/产物）不适用，走普通组件流程；"关于 AI 用量的仪表盘"是 Read 页，也不适用。
>
> 一句话定位：仪表盘败于不可读，向导败于不可完成，**这一页败于不可信**——所有规则都为"让用户敢让它继续跑"服务。
>
> 来源：Adapted from finesse-ui ai-console（github.com/mouse-lin/finesse-skill，MIT License），2026-09 吸收。dials：VARIANCE 2-4 / MOTION 2-4 / DENSITY 6-9。

## 判定与竞品区分

- **是 AI 工作台**：有指令框产生*动作*而非仅回答；有队列（等待/运行/完成）；输出流式或异步且会中途失败；用户是**监督者**而非执行者。
- **不是**：无工具的聊天（= 组件 + 消息列表）；AI 用量统计页（= Read 页）；产出保存配置的提示词表单（= 工作流向导）。
- **裁决问句**（brief 只说"AI 工作台"时）：*这个页面主要是在等 AI 干完活，还是在看它干过的活？* 等活 → 本文件；看已完成的 → 普通仪表盘 + 一张运行记录卡。

## 三时态同屏

仪表盘只看过去，向导只在现在；工作台必须**同屏**呈现三个时态——用户的下一个决策取决于麻烦在哪一个时态里：

```
FUTURE   队列 / 计划 / 定时任务      "接下来会发生什么,能不能在发生前叫停"
PRESENT  正在进行的 run,逐步         "现在在干什么,是不是卡住了"
PAST     历史 / 产物 / 成本          "发生过什么,为什么,产出了什么"
```

- **不许导航就能到达三个时态**——不是三个 tab，是三个区域。"看一眼队列还要点一下"的队列没人信，没人信的队列会静默烧预算。
- 桌面最廉价正确实现 = 三栏 shell（队列 | 运行流 | 历史/产物）；手机 = 顶部钉住条（FUTURE）+ 流（PRESENT）+ 底部 sheet（PAST）。
- **不可接受**：只显示现在——所有聊天 UI 的通病，也是它们都做不成工作台的原因。

## 运行流（Run Stream）—— 取代图表的承重构件

垂直、按时间排序的步骤列表，一行一步，新的在底部；**仅当用户本就停在底部时才自动滚动**。

### 行（折叠即可读）

```
[图标] [步骤标签]                        [耗时] [展开箭头]
       ↳ 结果第一行,截断
```

- **图标承载步骤类型**（思考 · 工具调用 · 文件写入 · 网络 · 等你 · 产出）。按**形状**区分而非只按色相——色盲与历史灰行场景下纯色相失效。
- **标签写工具和对象**，不写类别：`读取 orders.csv (2,481 行)` 而非 `工具调用`。一串 `工具调用 ×7` 是穿了马甲的进度条。
- **每步必显耗时**——这是用户区分"慢"和"卡"的唯一依据，他每隔几秒就在做这个判断。
- 行与行之间用 1px 竖轨（穿过图标列）连接，读作**一个过程**而不是一堆通知。

### 展开即可审计

成功步骤默认折叠，**失败步骤默认展开**（要点开才看得到的失败 = 被藏起来的失败）。展开区只放证据：

```
入参    { "file": "orders.csv", "sheet": "2026-Q2" }
出参    3 columns changed · 2,481 rows scanned        [查看完整结果]
耗时    1.42s          token —
```

- 载荷用等宽字体、数字用 `tabular-nums`、块高 ~240px 内部滚动。**禁止把工具载荷渲染成散文**——证据的价值在于逐字，美化会毁掉唯一重要的属性。
- 流式文字只允许出现在步骤输出块内部：≤1 chunk/帧、带块光标、**可跳过**（点击或 Esc 直达终稿）。
- 两条硬规则：流**不是** loading 指示（步骤轨独立承担"进行到哪"）；流到达时容器**不得引起页面回流**（预留高度或只向下生长）——把停止按钮顶得到处跑的界面是主动敌意。

## 九种运行状态

组件有八态（见 [`../../commands/component.md`](../../commands/component.md)）；**run 是另一种动物**，九态在队列、流行、历史表三处复用同一套视觉语言，token 层命名一次：

| 状态 | 读作 | 必须提供 | 缺它的代价 |
| --- | --- | --- | --- |
| `queued` 等待 | 置灰行 + 序号 | 移出队列 | 分不清"没开始"和"卡了" |
| `thinking` 思考 | 轨上脉冲点 + 已耗时 | 停止 | 经典无限 spinner |
| `tool` 工具中 | 工具名 + 该行 spinner | 停止 | 看不见它在碰什么 |
| `streaming` 输出中 | 实时文字 + 光标 | 停止、跳过动画 | — |
| `awaiting-input` 等你 | **accent 实底卡**，无声但无法错过 | 批准 / 修改 / 拒绝 | run 静默阻塞,一小时后才被发现 |
| `succeeded` 成功 | 对勾、弱化、折叠 | 打开产物、重跑 | — |
| `failed` 失败 | `--down` 色、默认展开、错误原文 | **从该步重试**、全部重试、复制错误 | 只给全部重试 = 让用户为 agent 的错误纳税 |
| `stopped` 已停止 | 半色调 + "被你在第 4/9 步停止" | 恢复、丢弃 | 分不清人为停止和崩溃 |
| `partial` 部分成功 | 成功带警告 | **查看被跳过的 81 条** | **没人做但人人需要**：2,400/2,481 行不是成功,渲染成绿色 = 数据管线静默丢 81 行六周。给独立色槽 `--warn` |

## 停止是一级控件

本 register 最常被违反的规则。仪表盘的主操作是筛选，向导是提交，**这里是停止**——与提交按钮同级、常驻（不随滚动消失）、点击即刻生效无需确认。运行中的每一屏都够得到它。

## 审批卡（Human-in-the-Loop）

agent 做**后果重大且不可逆**的事（发消息给客户 / 写生产表 / 花钱 / 发布）前，run 停下，**在流内原地**发出审批卡——用户正看着的地方。四段式，顺序固定：

```
要做什么   给 37 位客户发送补发优惠券短信
影响什么   37 条短信 · ¥0.06/条 · 预计 ¥2.22 · 不可撤回
凭什么     ↳ 基于第 3 步筛出的「已付款未发货 > 48h」名单   [查看名单]
           [ 批准并继续 ]  [ 改一下 ]  [ 拒绝 ]
```

- **"凭什么"是最常被砍、却决定答案的一段**——没有证据回链的审批卡是在让用户信任陌生人。必须指认产出名单的那一步，且可点击。
- **吓人的数字排大**：钱、量、不可逆性用 `--warn`/`--down` 大字号。37 不是细节，37 就是整个决策。
- **"改一下"不可省**：只有批准/拒绝会逼用户为改一个参数全程重跑，这会训练出"无脑批准"。
- **卡阻塞的是 run 不是页面**：其他 run 继续跑、历史仍可看。在这里用 modal 错两次——遮住证据，且暗示整个工作台停摆。
- **绝不预勾危险选项**；卡上必须写超时策略（无人应答时自动批准是有计划的 bug；自动取消可以，但要写明）。

## 成本与上下文是一等公民

本 register 的成本是按次、可变、不可见的——恰好是"一张意外账单之后被弃用"的东西的特征。

- **run 尾行**：`9 步 · 42.6s · 18.2k token · ¥0.41`。等宽、tabular、安静——是收据行，不是徽章不是图表。
- **每步 token 数放在展开行**（折叠行只放耗时）；折叠态全放 token 会把流变成表格。
- **预算是有界量表不是数字**：`¥18.4 / ¥50 本月` + 细填充条；80% 进 `--warn`、100% 进 `--down` 并说明 100% 时真正会发生什么（停？降速？）。
- **上下文压力是真实状态**：长 run 开始丢弃早期上下文时，在流里作为一步说出来（`↳ 上下文已裁剪，丢弃了第 1-3 步的原文`）。静默截断就是"它忘了我跟它说的话"——用户会把这归罪于整个产品。
- **模型身份是 run 的元数据**：头部显示一次；只有混用模型时才逐步显示。常驻的模型选择器是设置页入侵工作台。

## 色彩与动效

- 本页**不需要 hero 也不需要氛围动效**；动效预算几乎全部给状态转场族（ROUTING §3.9，R3 路线）：新行进入、状态翻转变色、展开塌陷。
- `awaiting-input` 用一次 accent 提亮（或一次性入场动画）标记"需要你"；其余状态转换 ≤ 250ms。
- 骨架到内容、乐观更新（点停止立即置灰该 run）都是 R3 免费能力。
- 深浅色默认跟随 Operate 模式（Restrained：中性 + 单强调），`--warn`/`--down` 是本页高频色槽，需在 token 层显式定义。

## 反模式（自检）

- [ ] 只有三时态之一（尤其只有 PRESENT 的"聊天壳工作台"）
- [ ] 步骤行折叠态读不出工具和对象（`工具调用 ×7`）
- [ ] 失败默认折叠
- [ ] `partial` 渲染成成功
- [ ] 停止按钮藏在菜单里 / 随滚动消失 / 需要确认弹窗
- [ ] 审批卡缺"凭什么"证据回链 / 用 modal 实现
- [ ] 只有批准/拒绝，没有"改一下"
- [ ] 成本只有总数没有预算量表 / 静默截断上下文
- [ ] 给这页加粒子/氛围/视差（品牌语法入侵工作台）
