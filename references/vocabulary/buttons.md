# 按钮卡片交互反馈命名词汇

> 术语库。反馈跟着手指不跟控件,多条动画必须同频,本表标准化按钮与卡片的动效反馈模式,是 [`micro-interactions.md`](micro-interactions.md) 的参数级补充。来源:视频研究 v02(12 种高级交互)+ v07(卡片与按钮 8 交互);2026-10 同源视频逐帧复核,见文末「同源视频帧复核」节。

| `card-fling`              | 甩得快就多翻一张                        | page=round(offset/pitch)+v·1.15,OFFSET 按张计                  | 卡片翻页/轮播       |
| `card-layout-morph`       | 列表↔网格是同一批卡                     | 位置/尺寸/圆角全按 t 插值;卡高 179↔97px                        | 列表网格换版式      |

## 使用规则

- 反馈跟着手指走,不跟着控件走(水波从点击点散开,不从按钮中心)
- 多条动画必须同频(同一时长同一缓动),看起来才像同一个东西;各用各的缓动 = 几个东西在动
- 卡片状态有来处和去处:从被点的按钮处长出(transform-origin),关闭时原路收回,禁止屏幕中心凭空淡入
- 筛选要处理"走的、留的、来的"三种卡,给三条不一样的曲线且序贯不重叠,才能分清谁走谁留
- 结果长在按钮身上(一枚按钮三种状态),视线一次都不用挪
- 反馈分量与动作重要性匹配:小操作不爆效,关键动作不无声
- 整页进入操作态时元素要有主次错动,禁止全部同时动

## 在 draw-md 中的写法

```markdown
## Button (submit-cta)
- pattern: btn-commit-morph
- press: { curve: cubic-bezier(.34,1.56,.64,1) }
- states: { width: [53, 308, 224], phase: [LOAD, IDLE, DONE] }
- done: { draw: check, origin: button }
- fallback: [prefers-reduced-motion]
```

## 同源视频帧复核

### 描述词对照(转录)

| # | 模式名 | 交互方式描述 |
| --- | --- | --- |
| 01 | `card-pop-origin` | 按钮生长式弹出:卡片从被点击的按钮位置长出来,放大到位后微冲过头再收回,关闭时原路退回,用户能清晰感知卡片和按钮的归属关系。 |
| 02 | `btn-commit-morph` | 按钮变形提交:提交按钮自身变成宽按钮→收圆→圆环旋转→撑开成条,全程不跳页不弹窗,视觉连续。 |
| 03 | `card-fling` | 轮播手势:慢拖过半松手翻一页,用力甩一下即使没拖远也翻多页,拖距和甩速都计入翻页逻辑,两侧卡片随距离缩放。 |
| 04 | `card-layout-morph` | 列表变网格:同一批卡片原地重排,横图变方图、标题收一行、价签挪到底,中间任意帧都保持语义通顺。 |
| 05 | `filter-3curves` | 筛选动态布局:被筛掉的卡片原地缩小淡出,留下的弹簧滑动到新位置,新进来的从空槽弹出,三种走位曲线不同便于区分。 |
| 06 | `card-tilt-depth` | 3D 倾斜卡片:手指触碰后卡面倾斜、高光随倾斜方向扫过,图案比卡面多动一点产生厚度感。 |
| 07 | `press-peek` | 长按悬浮操作:长按 400ms 卡片浮起、背后内容后推,可松手回落、上拖执行或拖出取消,全程可逆。 |
| 08 | `select-mode-shift` | 多选整页态变:长按一张卡触发全选模式,所有卡片缩小、勾选圈出现、标题变已选数量、底部升起操作条,整页统一反馈。 |
