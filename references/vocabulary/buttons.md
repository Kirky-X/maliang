# 按钮卡片交互反馈命名词汇

> 术语库。反馈跟着手指不跟控件,多条动画必须同频,本表标准化按钮与卡片的动效反馈模式,是 [`micro-interactions.md`](micro-interactions.md) 的参数级补充。来源:视频研究 v02(12 种高级交互)+ v07(卡片与按钮 8 交互)。

## 命名表

| 模式名                    | 视觉特征                                 | 关键参数                                                        | 适用场景            |
| ------------------------- | ---------------------------------------- | --------------------------------------------------------------- | ------------------- |
| `btn-spring`              | 按压回弹,越过终点再弹回                 | cubic-bezier(.34,1.56,.64,1)                                    | 所有可点按钮        |
| `btn-squash`              | 弹性开关,起步拉长落位压回               | 动 width 不动 scale(用 scale 比例失真)                       | 开关/切换           |
| `btn-ripple`              | 水波从点击点散开,不跟控件               | 小圆点放大 16 倍同时淡出,父级裁成按钮形状                      | 按钮/卡片点击       |
| `btn-burst`               | 点击爆散,粒子庆祝                       | 主体 .7→1.28→1;6 颗粒子晚 0.1s 起步                            | 点赞/收藏等关键动作 |
| `btn-draw-check`          | 成功勾选,描边接力                       | 圆先画完,勾才切入(成功要有过程)                              | 完成状态展示        |
| `slider-liquid`           | 液态滑块,整体像同一个东西               | 轨道/滑钮/数值三动画同时长同缓动                                | 滑杆/调节数值       |
| `num-count-up`            | 数字滚动,末位稳住不急刹                 | rAF + easeOutCubic                                              | 数据展示            |
| `skeleton-shimmer`        | 骨架落位,扫光只做位移                   | 骨架高度=真实内容高度,否则内容到达会跳                          | 加载占位            |
| `card-flip-3d`            | 卡片翻面,正反面各自藏好背面             | perspective + preserve-3d + backface-visibility: hidden         | 卡片翻转            |
| `icon-morph-burger`       | 汉堡变叉,一个元素从头走到尾             | 两线各平移 8px 再旋 ±45°,中线同时塌缩                          | 菜单开合            |
| `card-stack-pull`         | 卡组抽卡,后卡露出投影                   | 后卡位移 7/14px,拖拽时投影加深                                  | 卡片堆叠/划卡       |
| `drawer-pause-keyframe`   | 抽屉入场,状态靠"停住"被读出来          | 关键帧 34%→72% 之间留一段停顿                                   | 抽屉入场            |
| `card-pop-origin`         | 卡片从被点按钮处长出                    | transform-origin=按钮坐标;overshoot 0.8;关闭原路收回           | 列表点按钮开卡片    |
| `btn-commit-morph`        | 一枚按钮三态,结果长在按钮身上           | width 53→308→224px,STATE LOAD→IDLE→DONE,宽钮收成圆再画勾       | 提交/加载反馈       |
| `card-fling`              | 甩得快就多翻一张                        | page=round(offset/pitch)+v·1.15,OFFSET 按张计                  | 卡片翻页/轮播       |
| `card-layout-morph`       | 列表↔网格是同一批卡                     | 位置/尺寸/圆角全按 t 插值;卡高 179↔97px                        | 列表网格换版式      |
| `filter-3curves`          | 筛选分"走的/留的/来的"三条曲线        | 序贯不重叠:离场原地膨胀→留下的弹簧归位→新进最后出;OUT·MOVE·IN=5·4·2 | 列表筛选增删        |
| `card-tilt-depth`         | 券卡有厚度,图案比卡面动得快             | 层深倍率 0.4/1.0/1.6;层移 8·20·32px;旋转 ±9°;高光随倾斜扫过  | 会员卡/票券 3D 倾斜 |
| `press-peek`              | 一次长按三种结局,中途可改主意           | 不足 400ms 不浮起;LIFT 1.060;同轨道分支 DISMISS/ACT/CANCEL      | 长按预览菜单        |
| `select-mode-shift`       | 整页切操作态,元素错动有主次             | 让位 30→35px;标题变已选数量(1/5)                             | 多选批量操作        |

## 使用规则

- 反馈跟着手指走,不跟着控件走(水波从点击点散开,不从按钮中心)
- 多条动画必须同频(同一时长同一缓动),看起来才像同一个东西;各用各的缓动 = 几个东西在动
- 卡片状态有来处和去处:从被点的按钮处长出(transform-origin),关闭时原路收回,禁止屏幕中心凭空淡入
- 筛选要处理"走的、留的、来的"三种卡,给三条不一样的曲线且序贯不重叠,才能分清谁走谁留
- 结果长在按钮身上(一枚按钮三种状态),视线一次都不用挪
- 反馈分量与动作重要性匹配:小操作不爆效,关键动作不无声
- 整页进入操作态时元素要有主次错动,禁止全部同时动

## 在 draw-md 中的写法

```markdown
## Button (submit-cta)
- pattern: btn-commit-morph
- press: { curve: cubic-bezier(.34,1.56,.64,1) }
- states: { width: [53, 308, 224], phase: [LOAD, IDLE, DONE] }
- done: { draw: check, origin: button }
- fallback: [prefers-reduced-motion]
```
