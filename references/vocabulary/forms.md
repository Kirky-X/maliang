# 表单模式命名词汇

> 术语库。表单与输入控件的模式化命名,统一"结构 + 校验时机 + 反馈位置"的选型语言。

## 命名表

| 模式名                     | 视觉/行为特征                                                              | 适用场景                                            |
| -------------------------- | -------------------------------------------------------------------------- | ---------------------------------------------------- |
| `form-basic`               | 单列纵向,标签在上、输入在下,一个主提交按钮                                  | 通用信息采集                |
| `form-inline`              | 单行水平排布,回车即提交,无独立错误摘要区                                    | 搜索框、订阅条、快捷筛选                             |
| `form-wizard`              | 多步分步,步骤指示器,每步只问一件事,步内校验后前进                           | 注册引导、复杂开户、结账流程                         |
| `form-section`             | 长表单分组:组标题 + 描述,可配锚点导航                                       | 设置页、长问卷、详情编辑                             |
| `field-group`              | 输入组:前缀/后缀图标、单位或内嵌按钮                                        | 金额带单位、网址带协议、搜索框内嵌按钮               |
| `input-otp`                | 验证码分格,`type="text" + inputmode="numeric" + autocomplete="one-time-code"`,满位自动提交;数字自下方 8px 弹入(约 180ms),粘贴 6 位依次错开约 40ms 落下,当前格高亮+闪烁光标 | 短信/邮箱验证码 |
| `input-masked`             | 格式掩码自动分隔,宽容空格/连字符/标点等杂字符                               | 电话、卡号、邮编     |
| `input-password-reveal`    | Show/Hide 明文切换,提交时还原为密文类型                                     | 注册/登录密码框             |
| `input-password-strength`  | 实时强度计 + 要求清单逐项勾选;分格条每格约 250ms 带回弹填满,颜色红→橙→黄→绿随强度平滑过渡,提示文字同步淡出上移/淡入 | 注册设置密码            |
| `select-searchable`        | combobox:输入框 + 折叠弹层列表,可输入过滤,键盘上下键 + Enter 选择            | 选项 > 10 的选择器:国家、城市、标签(W3C APG)       |
| `input-character-count`    | 实时字数计数,接近/超限即提示                                                | 有上限的简介、留言         |
| `validate-on-submit`       | 提交时统一校验,失败整页回显并保留已填值                                     | 默认校验时机      |
| `validate-inline`          | 错误文案显示在对应字段下方,aria-describedby 关联                            | 所有字段的行内反馈           |
| `error-summary`            | 页面顶部汇总面板:标题 + 逐条错误链接回字段,自动聚焦 + role="alert",仅 1 条错误也要显示 | 服务端校验失败回显           |
| `form-autosave`            | 草稿自动保存/离开保留已填值,失败回显不重输                                  | 长表单、多步向导         |
| `field-checkbox-group`     | 多选字段组:竖排列表 / 横排胶囊两种排布,勾选即时计数,可配最少/最多选中数校验           | 标签多选、兴趣/权限勾选、批量筛选条件(表格行首多选见 [`tables.md`](tables.md) `table-selectable`) |
| `select-basic`             | 常规下拉:点开弹层单选,无输入过滤,选中即收起                                   | 3-10 项短列表选择(分类/状态/时段);与 `select-searchable` 构成选项量级连续谱:<3 项用 radio 组,>10 项用 `select-searchable` |
| `upload-click` / `upload-drag` | 点击按钮选文件 / 拖拽区上传(拖入即高亮);文件类型与大小前置校验,上传中显进度、失败可重试;两变体共享"触发器 + 文件列表 + 进度 + 失败重试"结构 | 头像、附件、凭证、商品图上传                 |
| `field-date`               | 日期/时间选择字段:点按唤起选择器录入,与展示型日历(framework `calendar` 类)是录入/浏览两个交互域 | 预订、筛选区间、排期等日期/时间录入              |
| `input-tags-removable`     | 可删除标签组:点叉号标签缩成圆点淡出,后续标签依次平滑补位,输入框高度随之收缩 | 收件人/标签录入               |
| `input-floating-label`     | 浮动标题输入框:聚焦时提示文字缩小上移成左上角标题,边框高亮;为空失焦复原 | 表单空间紧张的移动端                            |
| `input-inline-mention`     | 正文联想浮层:输入时在光标旁弹出联想列表,实时筛选,选中以小标签嵌入正文,浮层收起 | 富文本 @提及/引用                               |
| `validate-error-shake`     | 错误水平轻晃:校验失败该输入框水平轻晃(3 下幅度递减约 10→6→3px,共约 400ms,手机配轻震)+边框变红,提示文字从下方滑入;摇完自动选中内容便于重输,重新输入红色淡出恢复 | 移动端行内错误反馈(与 `validate-inline` 组合,口径见 [`ux-rules.md`](../meta/ux-rules.md) inline-validation) |


## 使用规则

- 分工:[`ux-rules.md`](../meta/ux-rules.md) 管 Do/Don't 可核对规则(inline-validation、error-summary 等 slug),本表只管**模式命名与选型**,规则争议回链 ux-rules
- 校验时机首选 `validate-on-submit` + `error-summary` 成对出现;`validate-on-blur` 只用于强度计、字数上限等即时增益字段
- 表单按钮(主提交/次级取消)命名见 [buttons.md](buttons.md);错误确认与危险操作浮层见 [popups.md](popups.md)
- 表单容器、分栏与分组布局见 [layout.md](layout.md);提交等待/成功/禁用态命名见 [states.md](states.md)
- 密码字段配 `input-password-reveal`,不再加二次确认密码框;禁止 maxlength 截断
- 服务端校验永远保留:客户端校验只是增强,用户可绕过且 JS 可能失败
- 永不预填密码框:密码必须用户主动输入,任何"记住的密码"自动回填进新表单都是安全隐患;敏感输入(卡号/证件)掩码显示
- 分段控件(segmented)类型一致:同一分段控件要么全表达选中态、要么全执行动作,禁混用;段数上限宽界面 5-7 段、移动端 ≤5 段,段宽一致,单控件内文字与图标不混排
- 开关(toggle)表达状态不表达动作;状态差异不能只靠颜色(加形状/勾/点变化);父开关管理多个子项且子项状态不一致时显示 mixed 态(横线)
- radio 单选组 >5 项改下拉或搜索型选择;横排 radio 间距按最长标签等分,不做不等宽挤压
- 滑杆(slider)宽量程场景配文本框(精确输入)与步进器(整步微调);最小值在首端、最大值在尾端;非线性量程只标首尾刻度,不标中间
- 选择器(picker)就近弹出(编辑字段下方或同层),禁跳页选择;中长列表用 picker,超长列表用"列表+索引"可跳段;分钟档粒度放宽时必须整除 60(刻钟档 0/15/30/45)
- 字段宽度 ≈ 预期内容长度:邮编 6 位、手机 11 位,超宽字段暗示格式错误

### 控件选型补充

- **状态按钮(toggle button)不单独使用**:成组构成单选或多选组;单选组同时仅一个激活态;多选组可定义互斥对(选中一个自动取消另一个)
- **操作块(chip)两型**:页签型(内容切换,选中态须明显区分)与筛选型(收件人块等已选条目,带移除);宽度由内容决定,仅横向扩展不换行,文本不可为空
- **字符计数器**:格式"已输入/上限";恰达上限不变红(达标是合法态),继续超长才变红并抖动;密码输入不配计数器
- **带默认推荐值的输入**(新建/重命名/另存):初始状态全选文本便于整体替换;多行文本框扩展到约 10 行后转内部滚动,不再撑高
- **选项排序有逻辑**:被选概率从高到低、数值从小到大、操作从简到繁、风险从低到高
- **默认勾选不得违背意愿**:禁止借默认勾选诱导开启功能或趁人不注意改变设置——欺骗感直接摧毁信任
- **二元对立合并为一个勾选**:同意/不同意这类正反选项用单个勾选框,不用两个单选
- **重大开关切换加确认**:开关控制重要功能或产生重大影响时,切换时弹确认;开关开启引发的联动列表项未激活时置为不可用
- **滑杆三型选型**:外置手柄(轻量场景,界面更轻)/内置手柄(音量亮度类,调节反馈直观)/无手柄直角条(密集调节,降复杂度);固定档位用磁吸步进,两端预览图标/文字可点击增减;需读值时配跟随气泡显示当前值
- **选择器循环滚动仅限周期性数据**(季节/生肖等生活常识周期);年龄/体重/国家等有边界数据关闭循环以明确边界;滚轮选项配图高度 ≤40px 防裁剪;数字选项从小到大排序
- **评分条**:五星制,支持点击与滑动,滑动步幅默认 0.5 星;评分提交需明确反馈;不可操作型仅用于量化展示
- **分段按钮禁用于编辑类操作**(删除/添加/多选编辑)与一级导航(页面级切换用页签),仅作选项与视图切换
- **取色工具三型选型**:网格=离散标准色快速选(标注类);光谱=连续空间探索(主题/装扮),但难以精确复用同一色值,禁用于图表系列/分类标签等需复用色值的场景;HSB 滑块=专业精细控制,普通用户理解成本高。选色实时同步预览;高频换色场景用预设色盘承载,全量选择器只作补充入口
- **数字加减**:设最小/最大值防非法输入;涉及金额等重要数值的调整加确认弹窗

## 在 draw-md 中的写法

```markdown
## Form (checkout-address)
- pattern: form-section + validate-on-submit + error-summary
- fields:
  - { name: email, type: email, label: 邮箱, required: true }
  - { name: phone, pattern: input-masked, inputmode: tel }
  - { name: city, pattern: select-searchable, source: regions }
- submit: { type: button-primary, label: 提交, loading: states/loading }
- error: { summary: { focus: true, link_to_field: true }, inline: below-field }
```
