# 图表选型命名词汇

> 术语库。先看数据要回答什么问题(趋势/比较/占比/相关/流程),再查本表选型,不先挑好看的。来源:ui-ux-pro-max charts.csv(25 种精选 14)。

## 命名表

| 模式名              | 视觉特征                              | 适用场景                       | 禁用场景/阈值                                        |
| ------------------- | ------------------------------------- | ------------------------------ | ---------------------------------------------------- |
| `chart-line`        | 折线:时间轴上的升降与速率             | 时间序列趋势、进度             | <4 点(用 stat card)、>6 序列、无时间维度;<1000 点 SVG,≥1000 点 Canvas+降采样 |
| `chart-bar`         | 柱/条形:类别量级对比,降序排列         | ≤15 类别的排名比较             | >15 类(用表格);20-50 转横向,>50 分页表格;含时间维度改折线 |
| `chart-donut`       | 环形:部分-整体占比,最大块在 12 点方向 | ≤5 类、一块主导、重直觉不重精确 | >5 类、切片差 <5%、需精确值;上限 6 切片,超出转 100% 堆叠柱 |
| `chart-scatter`     | 散点/气泡:两连续变量的关系            | 相关性、聚类、离群点探索       | <20 点模式无意义;>5000 点先 hexbin/聚合;变量为类别改分组柱 |
| `chart-heatmap`     | 热力:2D 网格强度,冷到热渐变          | 小时×天等密度/强度模式         | <20 格(用柱状);需读精确值时附数值图例               |
| `chart-funnel`      | 漏斗:阶段转化与流失,标注阶段间 %      | 顺序流程的转化分析             | 阶段非顺序、值不单调递减、<3 阶段;3-8 段最佳,>8 段并入 Other |
| `chart-gauge`       | 仪表:单 KPI 对目标线                  | 仪表盘单指标 vs 阈值           | 无目标基准禁用;≥3 个 KPI 改 bullet 网格              |
| `chart-forecast`    | 实线历史+虚线预测+置信带              | 历史+预测,向非技术受众传达不确定性 | 无历史基线禁用;历史窗口 30-90 天,预测 ≤30% 可见 x 轴 |
| `chart-waterfall`   | 瀑布:正负项逐段累加成总量             | P&L、预算差异拆解              | 非可加数据禁用;4-12 根,>12 根聚合 Other             |
| `chart-radar`       | 雷达:同一组固定属性的多实体对比       | 5-8 轴的产品/方案对比          | >8 轴、需精确比较;每组图 ≤2-3 个数据集               |
| `chart-treemap`     | 树图:层级面积占比,白描边分隔          | 预算/构成等层级拆解总览        | 层级 >3 层禁用;<200 节点 SVG,>1000 先分页/预过滤    |
| `chart-sankey`      | 桑基:节点间流量,源到目标渐变          | 多源→多目标的量分配            | 成环(改网络图)、<3 对流;<50 条 SVG,>200 条聚合 Other |
| `chart-waffle`      | 华夫:10×10 格填充表示占比             | 百分比进度、部分-整体直觉展示  | >5 类、需精确值、极小空间禁用                        |
| `chart-candlestick` | K 线:开高低收,阳线空心/阴线实心      | 金融交易场景的 OHLC 数据       | 非金融受众、无障碍优先场景禁用;同屏最多 500 根       |

## 使用规则

- <4 个数据点用 stat card,不用图表
- >6 条序列是视觉噪声:先聚合、分面或让用户筛选,不要一图全塞
- ≥1000 点用 Canvas + 降采样;>10000 点先聚合到区间再画
- 无障碍 fallback=可见数据表 + 文字摘要;键盘 focus 显示数值;序列用线型/形状/直接标注区分,禁止只靠色相
- 主序列用单一主色,填充约 20% 透明度;对比类目降序排列
- 占比超过 6 类一律转 100% 堆叠柱,不再切饼
- 预测场景固定语法:实线=实际,虚线=预测,置信带用同色低透明填充
- 地图/网络/3D/词云等类型在移动端为高风险场景,小屏优先降级为表格或柱状
- 桑基、漏斗标注意义:漏斗必须标阶段间转化 %,桑基必须保留节点标签;最大流失段高亮

## 在 draw-md 中的写法

```markdown
## Chart (trend-main)
- pattern: chart-line
- data: { series: 2, points: 1200 }
- render: { engine: canvas, downsample: true }
- labels: direct
- fallback: { table: visible, summary: trend-text }
- a11y: { styles: [solid, dashed], keyboard: focus-reveal }
```
