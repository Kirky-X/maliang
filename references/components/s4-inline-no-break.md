# S4 · 行内不断章（Inline No-break）

> 区段标题是嵌在正文流里的小型大写短语：不另起一行、不断章。散文主导页面的区段头。

## 名称与形状

标题以 `all-small-caps` 短语形式出现在段落内部（如「……由此引出 **本章要点** ——」），阅读动线完全连续。没有空间断章，靠字型变化标记章节。

## 变体旋钮

| 旋钮 | 可选值（逐旋钮取一值，写入构建盖章） |
| --- | --- |
| 标记法 | 小型大写 · 字重 500 · accent 着色 |
| 位置 | 段首 · 段中 · 段末承接 |
| 后续 | 破折号接排 · 冒号接排 · 直接接排 |

## 何时用与勿混淆

- **何时用**：散文主导、要求连续阅读的页面；随笔、说明书、叙事型长文。
- **勿混淆**：[S2 悬置标题](s2-hanging.md)（用负空间断章）；[S5 底部锚定](s5-bottom-anchored.md)（标签在内容之后）。

## DOM+CSS 骨架

```html
<p>…正文续写，<span class="head-inline">一个小节标题。</span>正文从这里继续…</p>
```

```css
.head-inline { font-variant-caps: all-small-caps;
  letter-spacing: 0.06em; font-weight: 500; }
```

折叠要点：<60rem 与 <40rem 均无需处理——行内结构天然适应窄屏，这正是它的优点。

## 反模式

- 中文页面滥用小型大写——小型大写是西文排印机制，中文等价物是加字重或楷体/引语体（[font.md](../dimensions/font.md) 中文强调替换表），硬套 `all-small-caps` 对中文无效。
- 行内短语写得太长（超过一行）——它是路标不是标题；长了就换 [S2](s2-hanging.md)。
- 跨产出照抄同组旋钮值 = 同款；复用至少换一个旋钮并盖章声明。
