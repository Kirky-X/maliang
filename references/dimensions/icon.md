# 图标规范

> 规范层。图标的**尺寸、风格、命名、可触达**。具体硬值在产物层 [`examples/ui-markdown/token.md`](../../examples/ui-markdown/token.md)。

## 尺寸阶梯

| 用途            | 推荐尺寸 |
| --------------- | -------- |
| 导航/标签栏图标 | 24×24    |
| 列表/行内图标   | 20×20    |
| 辅助/提示图标   | 16×16    |
| 大图标/空状态   | 32×32+   |

基础栅格 24×24,图标按 24 网格设计,缩放到其他尺寸(20/16/32)时保持视觉重量一致。

## 图标风格选型

| 风格 | 视觉特征 | 代表套件(获取走 xizhi 路由) | 适用/注意 |
| --- | --- | --- | --- |
| 线性 Outlined/Stroke | 1.5~2px 均匀描边,无填充,端点圆角统一 | lucide / feather / tabler / radix | 默认首选;工具型/后台;小于 16px 易发虚,改用填充 |
| 填充 Filled/Solid | 整体色块填充,无描边 | material-symbols(filled) / antd / bootstrap | 选中态/主功能强调;小尺寸下比线性清晰 |
| 双色 Duotone | 主形实色+辅形半透明,两档色阶 | phosphor(duotone) / antd(two-tone) | 信息面板分层;两色须同源单主色派生 |
| 半填充 Semi-filled | 局部填充局部描边(圆内实、外圈线) | material-symbols 圆角填充变体 | 播放/录制等状态钮 |
| 系统字形 Glyph/Symbol | 符号字体,字重轴可变,随系统主题 | SF Symbols(代码 API) / sys.symbol / material-symbols(variable) | 原生平台默认;零下载自动跟随主题 |
| 扁平多彩 Flat Multicolor | 多色平涂,无渐变无光影 | iconify color 族(含 fluent-emoji) | 消费级/生活方式 App;企业后台慎用易闹 |
| 彩色拟物 Color-Skeuomorphic | 渐变+高光+投影的厚度感 | iconify 兜底彩色拟物族 | 营销页/空状态;正文功能图标密度大时禁 |
| 玻璃拟态 Glass | 半透明+背景模糊+高光边 | 平台图标层(如 iOS 液态玻璃层) | 必须垫彩色底,否则与白纸无异(见 [`glass-effect.md`](glass-effect.md)) |
| 等距 Isometric | 等距视角+三面光影 | iconify isometric 族 | 架构图/主题站;交互功能图标禁用 |
| 手绘 Doodle | 不均匀线条,涂鸦感 | iconify doodle 族 | 儿童/轻品牌;企业产品禁用 |
| 像素 Pixel | 像素网格硬边 | iconify pixelart 族 | 复古/游戏主题 |
| 动效 Animated | Lottie/变形动画 | lordicon / morphicons | loading/成功/空状态;一处一动效+reduced-motion 降级(见下节) |

风格选择锚定产品气质与平台:后台/工具型默认线性,品牌消费端可上双色/扁平多彩;彩色拟物/等距/像素属表达性主题档,正文功能图标禁用。App 图标(应用 logo/商店图)是品牌资产,走品牌设计流程,不在本表——本表只管界面内功能图标。

### 复刻配方(按档可执行参数)

- **线性**:24 网格;stroke 1.5~2px 全套一档;linecap/linejoin=round;禁填充;不规则形(播放三角/星)光学居中做进 padding;缩到 20px 保 stroke、16px 以下改填充档。
- **填充**:整块 path 填充;内部镂空 fill-rule=evenodd,负空间缝隙 ≥1.5px(细缝小尺寸糊死);圆角半径与同形线性版一致。
- **双色**:主形 100% 不透明,辅形同色相 40%~60% 不透明(或主色深浅两档);两形边界对齐共享轮廓;禁第三色。
- **半填充**:外轮廓走 stroke,内部主形走 fill,交界留 1px 缝;填充部分占比 40%~60%。
- **系统字形**:符号字体+字重轴(SF Symbols weight 七档);颜色全走 currentColor;不做固定色值资产。
- **扁平多彩**:2~4 色平涂;禁渐变禁投影;色板从主色同饱和度带派生;深色底加细描边或提升一档明度。
- **彩色拟物**:同色相三阶(亮部/中调/暗部)+顶部白高光(10%~20% 不透明)+下方投影(黑 20%~30%,模糊 2~4px);光源统一左上 45°;容器大圆角(近 squircle);整组图标共用同一光源与高光参数。
- **玻璃**:图标层半透明白 10%~20%+背景模糊+1px 内高光边;必须垫彩色底;配方细则见 [glass-effect.md](glass-effect.md)。
- **等距**:30° 等距轴;顶/侧/暗三面同色相三阶;线宽不随透视变化;禁与线性图标混排。
- **手绘**:线宽抖动 ±20%;端点刻意留 1~2px 缺口不闭合;圆用多段弧禁完美正圆;一组内抖动幅度统一。
- **像素**:16 或 32 网格;1px 硬边禁抗锯齿;色板 ≤4 色;禁半透明。
- **动效**:触发即动、静止终态清晰;时长与降级口径见下方动效图标节。

同一图标集 MUST 风格统一:描边粗细一致(推荐 1.5~2px stroke)、圆角一致、端点一致。**禁止混搭**(同一集里有的线性有的填充)。选中/未选中通过**同图标的线性↔填充切换**表达,不换图。
同一容器/同一列表/同一行内的同类图标 MUST 用同一尺寸档(同一 `{icon-size-*}` token);同排图标尺寸混用是对齐轴断裂的常见根因(判据见 [alignment.md](./alignment.md) 同排等高与行槽)。

## 命名

`icon_<语义>`,语义化而非具象:

- `icon_home` ✓(语义:首页)
- `icon_house_24_blue` ✗(具象 + 尺寸 + 颜色冗余)

尺寸/颜色由容器控制,不进图标名。

## 可触达性(费茨定律)

- 可点击图标的热区 ≥ 44×44pt(视觉图标可小于 24×24,但点击热区靠 padding 撑到 44×44)
- 图标 + 文字组合优于纯图标(降低识别成本)
- 关键操作 MUST 有文字标签,不可仅用图标

## 三性

- **识别性** — 图标含义自明,小尺寸下仍可辨
- **一致性** — 整套同风格、同粗细、同栅格
- **引导性** — 配合位置/颜色引导操作,而非仅装饰

### 光学与匹配

- **光学居中做进资产**:不规则形状(播放三角、收藏星)的视觉中心偏离几何中心时,把光学校正做进图标的 padding 里——使用方按几何放置即得光学居中;校正量通常很小但影响明显
- **字重匹配相邻文字**:图标笔画粗细与相邻文字字重一致(不想强调任何一方时);图文一粗一细会读成两个层级

## 颜色

图标颜色**继承文字色**(同 token),不单独定义图标色。状态变化(选中/禁用)遵循文字色的透明度/色相规则,与文字一致。

## 动效图标(设计决策层)

> 本节只回答**何时用、何约束、何降级**;图标库选型与资产下载一律走 xizhi skill(其路由已覆盖 lordicon 动效图标与 morphicons 变形库),maliang 不复述其 API,防双处维护。lordicon 原 GitHub 仓库已 deprecated,细节以 lordicon.com 官方现行文档为准。

### 何时值得动效化

对齐动效 GATE「有动机」([`INDEX.md`](../motion-skeletons/INDEX.md) §1):只有**状态语义需要动画来传达**时才做——状态切换(morph)、进行中(loading)、操作确认(click)。纯装饰性循环图标是 AI 味,砍。频率法则同样适用:每天几十次出现的图标,降为近乎无感或不做。

### 触发语义选型

| 触发 | 交互意图 | 典型例子 |
| --- | --- | --- |
| `in` | 元素入场时播一遍 | 页面加载后的品牌图标 |
| `click` | 点击确认反馈 | 提交按钮的✓ |
| `hover` | 悬停提示可交互 | 导航图标微动 |
| `morph` | 状态 A↔B 形变 | menu↔close、播放↔暂停、主题日月 |
| `loop` | 持续进行中 | loading、同步中 |
| `boomerang` | 去程即回程,单次 | 点赞弹一下回原位 |
| `sequence` | 多段叙事 | 引导、空状态小剧场 |

### 加载防 CLS 占位(三模式)

动效资产(Lottie JSON / JS 库)异步加载,不给占位会顶跳布局:

1. **同形静态占位**——先渲染同图标集的静态版,资产就绪后替换;
2. **固定尺寸盒**——容器写死 `width`/`height` 或 `aspect-ratio`,资产晚到不改变布局;
3. **骨架占位**——列表/卡片场景用 `micro-skeleton` 兜底。

### 硬约束

- **reduced-motion 必须有静止终态**:`prefers-reduced-motion: reduce` 时停在终态帧(或静态版),禁空白;与 GATE「有静止终态」同源。图标 morph 属动效降级三档的 **user 档**(跟随系统设置即可,见 [`../vocabulary/micro-interactions.md`](../vocabulary/micro-interactions.md) 三档口径)。
- **颜色走 token**:`currentColor` 或 `{color-*}` token,禁在动效资产内写死 hex——与上文「颜色继承文字色」同一决策,资产内嵌颜色会击穿主题切换。
- **morph 适用边界**:仅 stroke 同源图标、两端同一网格系统、统一描边粗细;跨图标集 morph 会形变穿帮。
- 状态切换优先复用静态切档的语义(线性↔填充表选中态),morph 只在切换本身值得传达时叠加,不重复表达。
