# 间距规范

> 规范层。间距的**基础单位、语义阶梯、分区策略**。具体硬值在产物层 [`examples/ui-markdown/token.md`](../../examples/ui-markdown/token.md)。

## 基础单位

以 2px 为基准(4 的倍数体系,2px 仅用于微调粒度)。所有间距 MUST 是 2 的倍数(2 / 4 / 6 / 8 / 12 / 14 / 16 / 20 / 24 / 32 …)。禁止奇数或任意像素值。

## 语义阶梯

| token       | 推荐值  | 用途                   |
| ----------- | ------- | ---------------------- |
| spacing-xs  | 4       | 图标内/紧凑组内        |
| spacing-sm  | 8       | 相关元素组内           |
| spacing-md  | 14 / 16 | 模块内边距、卡片内边距 |
| spacing-lg  | 20      | 页面边距(左右安全区)   |
| spacing-xl  | 24 / 32 | 模块间距(区块之间)     |
| spacing-2xl | 48+     | 大分区/章节间距        |

## 分区策略(六角色合同)

> **合同不是数值表**:下表规定每个间距角色**owns 什么、avoid 什么**;具体数值只允许引用已声明 token(见上「语义阶梯」与产物层 `token.md`),不新增第二套硬值。来源:styleseed 仓的 ss-resolve spacing 合同,2026-10 吸收。

| 角色 | 语义 | owns(管什么) | avoid(不许做什么) |
| --- | --- | --- | --- |
| `pageInset` | 屏幕边距 | 页面最外层左右内边距(安全区) | 嵌套面板逐层复施——子面板不再要一次 `pageInset` |
| `sectionGap` | 模块间距 | 相互独立的分区之间的纵向间隔 | 分隔标签与它的控件(那是 `stackGap` 的活) |
| `groupGap` | 组间距 | 同一 section 内成组内容之间的间隔 | 把每一行都当新组——相邻行属同组时用 `stackGap` |
| `stackGap` | 组内元素 | 紧密相关的纵向项目(标签→控件、标题→正文) | 拿它当所有主要页面边界的间隔(那是 `sectionGap`) |
| `inlineGap` | 行内元素 | 相关的水平项目(图标↔文字、并排按钮、表单控件对) | 靠压缩触控目标(< 44px)换留白 |
| `componentInset` | 模块内边距 | 有容器边界的组件内部的四周内边距 | 为「一致」给未容器化的文本凑内边距 |

- **值只允许引用已声明 token**:每个角色落到具体值时引用产物层已声明的 spacing token,禁止出现第二套自由像素值(硬编码检查见 [`../commands/draw-md.md`](../commands/draw-md.md)「组件参数表」的 token 引用硬约束与 preview-checklist 5.6)。
- **防别名自引用**:角色别名不得指向自身或互相循环引用(如 `groupGap → stackGap → groupGap`);引用链必须终止在一个原始 token 上。
- **邻近性法则优先于均匀**:相关的紧挨、不相关的拉开——组内间距必须小于组间间距(`stackGap` < `groupGap` < `sectionGap`),均匀间距等于没有分组。
- **边界句(必须遵守)**:数值吻合只证明**合同被执行**,不证明**节奏好看**。自动检查(数值对齐 / token 引用 / 邻接关系)全绿之后,仍必须看渲染画面复核节奏与层级——机器判合同,人判节奏。

**组内紧凑、组间宽松**——邻近性法则:相关的紧挨,不相关的拉开。这是用间距表达信息分组的核心手段。

## 双倍间距技巧

图标距容器边缘采用**双倍间距**(图标内边距 > 图标间距),较大形状用两倍大圆角,视觉更平衡(见 [radius.md](./radius.md))。
