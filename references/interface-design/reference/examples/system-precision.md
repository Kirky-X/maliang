# 设计系统 - 精密与密度

用于仪表盘/管理界面的示例系统

## 方向

**性格：** 精密与密度
**基础：** 冷（slate）
**深度：** 仅边框

## Tokens

### 间距
基准：4px
刻度：4, 8, 12, 16, 24, 32

### 颜色
```
--foreground: slate-900
--secondary: slate-600
--muted: slate-400
--faint: slate-200
--border: rgba(0, 0, 0, 0.08)
--accent: blue-600
```

### 圆角
刻度：4px, 6px, 8px（锐利、技术感）

### 排版
字体：system-ui（快速、原生）
刻度：11, 12, 13, 14（基准）, 16, 18
字重：400, 500, 600
等宽：SF Mono, Consolas（用于数据）

## 模式

### 按钮
- 高度：32px（紧凑）
- 内边距：8px 12px
- 圆角：4px
- 字体：13px，500 字重
- 边框：1px 实线

### 卡片
- 边框：0.5px 实线（faint）
- 内边距：12px
- 圆角：6px
- 无阴影

### 表格单元格
- 内边距：8px 12px
- 字体：13px tabular-nums
- 下边框：1px 实线（faint）

## 决策

| 决策 | 理由 | 日期 |
|------|------|------|
| 仅用边框 | 信息密度比悬浮感更重要 | 2026-01-15 |
| 紧凑尺寸 | 面向高级用户，高信息密度 | 2026-01-15 |
| 系统字体 | 性能、原生感 | — |
