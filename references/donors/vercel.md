# Vercel —— 工程静默(Geist 系统)

## 1. 视觉主题与氛围

把"开发者基础设施"做成隐形:近纯白画廊 + 近黑文本,每个元素为展示自己而挣得像素。极简不是装饰,是工程原则——界面像编译器对待代码:能删的 token 全删,只剩结构。差异化靠两件手艺:**shadow-as-border** 与**多层阴影栈**。

## 2. 色板与角色

| 角色 | 值 | 用途 |
| ---- | -- | ---- |
| 近黑(Vercel Black) | `#171717` | 主文本 / 标题 / 深底(微暖,不是纯黑) |
| 纯白 | `#ffffff` | 页面底 / 卡面 / 深底上的文字 |
| 灰 600 / 500 / 400 | `#4d4d4d` / `#666666` / `#808080` | 次文本 / 三级 / 占位与禁用 |
| 灰 100 / 50 | `#ebebeb` / `#fafafa` | 边框 / 微表面与内环高光 |
| 工流三色 | Ship `#ff5b4f` · Preview `#de1d8d` · Develop `#0a72ef` | **只做工作流步骤标记** |
| 链接蓝 / 焦点蓝 | `#0072f5` / `hsla(212,100%,48%,1)` | 链接 / 键盘焦点环 |
| 徽章蓝 | 底 `#ebf5ff` · 字 `#0068d6` | 状态 pill |

**用色分配**:系统无彩色——灰阶承担全部结构;三色只在"Develop → Preview → Ship"管线等流程语境出现,不做装饰。

## 3. 排版规则

- 字族:`Geist`(回退 Arial 等);`Geist Mono`(回退 ui-monospace / SFMono-Regular)供代码与技术标签
- **OpenType 全局开 `"liga"`**(连字是结构不是装饰);表格数字用 `"tnum"`
- **三档字重严格分工**:400(正文)/ 500(UI 交互)/ 600(标题强调);正文不用 700
- 字距随字号收紧(最激进档之一):48px/600/1.00-1.17/-2.4 至 -2.88px · 40px/600/1.20/-2.4px · 32px/600/1.25/-1.28px · 24px/600/1.33/-0.96px · 16px/500/1.50/normal;14px 以下 normal

## 4. 组件样式

| 组件 | 值 |
| ---- | -- |
| 主按钮(暗) | 背景 `#171717` · 文字 `#ffffff` · padding 8px 16px · 圆角 6px |
| 次按钮(白) | 背景 `#ffffff` · 文字 `#171717` · 圆角 6px · **边用阴影** `rgb(235,235,235) 0px 0px 0px 1px` |
| Pill 徽章 | 底 `#ebf5ff` · 字 `#0068d6` · 圆角 9999px · padding 0 10px · 12px/500 |
| 卡片 | 白底 · **无 CSS border** · 圆角 8px(标准)/12px(图片卡) · 阴影栈见 §6 |
| 图片卡 | `1px solid #ebebeb` 边 + 顶部圆角 `12px 12px 0 0` |
| 导航 | 白色 sticky · 链接 Geist 14px/500 `#171717` · 深色 pill CTA 右侧 |

## 5. 布局原则

- 基数 8px;主刻度 1/2/3/4/5/6/8/10/12/14/16/**32**/36/40px——**16 直接跳 32,没有 20/24**
- 内容最大宽约 1200px;hero 居中单列大顶距
- **画廊式空**:区块间距 80-120px+;白空间就是设计——"没什么要证明"
- 区块之间不靠底色变化,靠 shadow-border、全宽 1px `#171717` 分割线与间距

## 6. 深度与海拔

| 层 | 处理 | 用途 |
| -- | ---- | ---- |
| L0 | 无阴影 | 页面底 / 文本块 |
| L1 环 | `rgba(0,0,0,0.08) 0px 0px 0px 1px` | **shadow-as-border**,全站基础 |
| L1b 浅环 | `rgb(235,235,235) 0px 0px 0px 1px` | 页签 / 图片 |
| L2 微卡 | 环 + `rgba(0,0,0,0.04) 0px 2px 2px` | 标准卡 |
| L3 全卡 | 环 + 微抬 + `rgba(0,0,0,0.04) 0px 8px 8px -8px` + 内环 `#fafafa 0px 0px 0px 1px` | 特色卡 / 高亮面板 |

**阴影哲学**:每个阴影层有独立建筑职责——一层当"边框"(0 偏移 1px 扩散),一层环境柔化(2px 模糊),一层远距深度(8px 模糊负扩散),一层内环 `#fafafa` 让卡片"从内部发光"。卡片是**被建造出来的,不是漂浮的**。

## 7. Do's and Don'ts

**Do**:显示级激进负字距(-2.4 至 -2.88px@48)· shadow-as-border 替代 CSS border · 全局 `"liga"` · 400/500/600 三档 · 工流三色只在流程语境 · 多层阴影栈建卡 · 保持灰阶无彩 · 主文本用 `#171717`(微暖)
**Don't**:Geist 用正字距 · 正文 700 · 卡片用传统 CSS border · UI chrome 引入暖色/彩色 · 工流三色做装饰 · 阴影超过 0.1 不透明度 · 正文加字距 · pill 圆角用在主操作按钮 · 卡阴影省掉内环 `#fafafa`(它就是内发光)

## 8. 响应式

- 断点:400 / 600 / 768 / 1024 / 1200 / 1400px;导航折汉堡
- hero 48px 起随视口缩,负字距比例同步收紧;feature 卡 3 → 2 → 1 列
- 区块间距 80px+ → 移动端 48px;截图保持边处理,可横向滚动

## 9. Agent Prompt Guide

- 快速取色:CTA `#171717` · 底 `#ffffff` · 标题 `#171717` · 正文 `#4d4d4d` · 边(阴影)`rgba(0,0,0,0.08) 0px 0px 0px 1px` · 链接 `#0072f5` · 焦点 `hsla(212,100%,48%,1)`
- 例:"白底 hero:标题 48px Geist 600,行高 1.00,字距 -2.4px,色 `#171717`;副标 20px/400/1.80 `#4d4d4d`;暗 CTA(`#171717`,6px 圆角,8px 16px)+ 幽灵按钮(白底,shadow-border `rgba(0,0,0,0.08) 0px 0px 0px 1px`,6px 圆角)"
- 迭代纪律:① shadow-as-border 是地基 ② 字距随字号缩放(48px→-2.4px、32px→-1.28px、24px→-0.96px、14px normal)③ 只用 400/500/600 ④ 颜色是功能不是装饰 ⑤ 卡片阴影的内环 `#fafafa` 是内发光 ⑥ Geist Mono 大写做技术标签
