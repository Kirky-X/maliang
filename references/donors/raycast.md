# Raycast —— 桌面原生暗色(macOS 窗口物理)

## 1. 视觉主题与氛围

"黑曜石雕出的精密仪器内腔":背景是带蓝调的黑(`#07080a`),不像网页,像 macOS 原生应用。签名手艺是**借自 macOS 窗口 chrome 的多层阴影**——inset 高光 + 底部内暗,让卡片与按钮像桌面上真实压/抬的玻璃件。红色(`#FF6363`)只做标点,不做主色。

## 2. 色板与角色

| 角色 | 值 | 用途 |
| ---- | -- | ---- |
| 近黑蓝 | `#07080a` | 页面画布(蓝冷底调,非纯黑) |
| 表面 100 | `#101111` | 抬升表面 / 卡片 |
| 卡片面 | `#1b1c1e` | 徽章底 / 标签填充 |
| 亮白 | `#f9f9f9` | 主文本 / 高强调 |
| 浅灰 | `#cecece` | 次级正文 / 描述 |
| 银灰 | `#c0c0c0` | 三级文本 / 弱标签 |
| 中灰 | `#9c9c9d` | 链接默认 / 次导航 |
| 暗灰 | `#6a6b6c` / `#434345` | 禁用 / 静默边框与未激活项 |
| 边框 | `hsl(195,5%,15%)`(≈`#252829`) | 卡片 / 分隔标准边 |
| 品牌红 | `#FF6363` | hero 斜条纹 / 危险态——**标点色** |
| 交互蓝 | `hsl(202,100%,67%)`(≈`#55b3ff`) | 链接 / 焦点 / 选中 |
| 键盘键渐变 | `#121212 → #0d0d0d` | 快捷键键帽 |
| 暖光晕 | `rgba(215,201,175,0.05)` | 特色元素后的氛围 |

**用色分配**:红是品牌标点(hero 与危险态),蓝是交互/信息色,绿黄只做语义状态——三者互不越位。

## 3. 排版规则

- 字族:`Inter`(全站);`GeistMono` 供代码;OpenType 全局 `calt, kern, liga, ss03`,显示文本加 `ss02, ss08`,hero 标题 `"liga" 0`
- **正字距签名**:正文 +0.2px、按钮/导航 +0.3px、小链接 +0.4px——暗底上少见的"透气"处理,是 Raycast 与别的暗色 UI 的分野
- **正文基线 500**:body 默认 medium 而非 regular——暗面文字更实,不发虚
- 四元组示例:64px/600/1.10/0(hero)· 56px/400/1.17/+0.2px · 24px/500/normal/+0.2px · 16px/500/1.60/+0.2px · 14px/500/1.14/+0.2px · 12px/600/1.33/0

## 4. 组件样式

| 组件 | 值 |
| ---- | -- |
| 主 CTA(pill) | 半透明白底 `hsla(0,0%,100%,0.815)` · 深字 `#18191a` · pill 形 · hover 全白 |
| 次按钮 | 透明底 · 白字 · 6px 圆角 · 边 `1px solid rgba(255,255,255,0.1)` · 微投影 `rgba(0,0,0,0.03) 0px 7px 3px` |
| Ghost | 无底无边 · 字 `#6a6b6c` · pill 形 · hover 提亮至白 |
| 卡片 | 面 `#101111` · 边 `1px solid rgba(255,255,255,0.06)` · 圆角 12-16px |
| 抬高卡 | **双环**:外环 `rgb(27,28,30) 0px 0px 0px 1px` + 内环 `rgb(7,8,10) 0px 0px 0px 1px inset` |
| 键帽 | 渐变 `#121212 → #0d0d0d` · 5 层阴影栈(见 §6)· 4-6px 圆角 · 12px/600 |
| hover 过渡 | **只用 opacity(0.6)**,不做颜色切换——签名交互范式 |

## 5. 布局原则

- 基数 8px;刻度 1/2/3/4/8/10/12/16/20/24/32/40px;区块纵向间距 80-120px;卡内边距 16-32px
- 内容最大宽约 1200px(断点 1204px),居中
- **戏剧性负空间**:区块漂浮在大暗场里,营造电影式节拍
- **产品密、营销疏**:产品截图信息密集,周边营销文案极少、间距慷慨

## 6. 深度与海拔

| 层 | 处理 | 用途 |
| -- | ---- | ---- |
| L0 虚空 | 无阴影,`#07080a` | 页面底 |
| L1 微 | `rgba(0,0,0,0.28) 0px 1.189px 2.377px` | 行内体微抬 |
| L2 双环 | 外环 `rgb(27,28,30) 0 0 0 1px` + 内环 `rgb(7,8,10) 0 0 0 1px inset` | 卡片围合 |
| L3 按钮 | `rgba(255,255,255,0.05) 0px 1px 0px 0px inset` + `rgba(255,255,255,0.25) 0px 0px 0px 1px` + `rgba(0,0,0,0.2) 0px -1px 0px 0px inset` | macOS 式按压件:上白高光 + 下内暗 |
| L5 浮动 | `rgba(0,0,0,0.5) 0px 0px 0px 2px` + `rgba(255,255,255,0.19) 0px 0px 14px` + inset 组 | 命令面板 / 浮动层 |

**阴影哲学**:外层环围合(替代边框)+ **inset 顶高光**(`rgba(255,255,255,0.05-0.25)`,光从上来)+ **inset 底暗**(`rgba(0,0,0,0.2)`,影在下面)——效果是物理的:玻璃与拉丝金属,不是平面矩形。**阴影永远成对(外 + 内)**。

## 7. Do's and Don'ts

**Do**:`#07080a` 蓝调黑(非纯黑)· 正文 +0.2px 正字距 · 多层 inset 阴影 · 品牌红只做标点(hero 与错误态)· `rgba(255,255,255,0.06)` 卡边 · 正文基线 500 · 主 CTA pill(86px+ 圆角)、次操作 6-8px · OpenType `calt, kern, liga, ss03` · hover 用 opacity 0.6
**Don't**:纯黑 `#000000` 背景 · 正文负字距 · 蓝色做主品牌色(蓝是交互,红是品牌)· 单层平阴影 · 有 500 可用时用 400 正文 · 混暖冷边框(守冷灰)· 无 inset 伴生的重投影 · 装饰渐变与彩色底(暗场是舞台,内容是演员)

## 8. 响应式

- 断点:600 / 768 / 1024 / 1200px;导航折汉堡 + 抽屉
- hero 64 → 48 → 36px;feature 卡 3 → 2 → 1 列;键帽展示在移动端隐藏
- 产品截图按固定比例缩放,macOS 窗口圆角与阴影处理全程保持

## 9. Agent Prompt Guide

- 快速取色:底 `#07080a` · 主文本 `#f9f9f9` · 品牌红 `#FF6363` · 交互蓝 `hsl(202,100%,67%)` · 次文本 `#9c9c9d` · 卡面 `#101111` · 边框 `hsl(195,5%,15%)`
- 例:"在 `#07080a` 上做 hero:64px Inter 600,行高 1.1,近白文本 `#f9f9f9`;半透明白 pill CTA(`hsla(0,0%,100%,0.815)`,86px 圆角,深字 `#18191a`)";"做一张 feature 卡:`#101111` 底,`1px solid rgba(255,255,255,0.06)` 边,16px 圆角,双环阴影(外环 `rgb(27,28,30) 0 0 0 1px`),22px Inter 标题,`#9c9c9d` 正文"
- 迭代纪律:① 背景必须是 `#07080a` 不是纯黑 ② 正文正字距(+0.2px)③ 阴影必有外层 + inset 双层 ④ Inter 开 `calt, kern, liga, ss03` ⑤ hover 用 opacity 切换(0.6)不是换色
