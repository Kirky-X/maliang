# Linear —— 暗色原生精密工程

## 1. 视觉主题与氛围

近黑画布上的精密工程:内容像星光从黑暗里浮现,层级靠白透明度与亮度的微差管理。**暗色是原生介质,不是给亮色设计套的主题**。密度高但安静,自发光文本(`#f7f8f8`)替代纯白防疲劳。

## 2. 色板与角色

| 角色 | 值 | 用途 |
| ---- | -- | ---- |
| 营销黑 | `#010102` / `#08090a` | 页面最深背景(hero / 营销页) |
| 面板 | `#0f1011` | 侧栏 / 面板背景 |
| 表面 L3 | `#191a1b` | 卡片 / 下拉 / 浮层 |
| 次级表面 | `#28282c` | hover 态 / 微抬升组件 |
| 主文本 | `#f7f8f8` | 默认文本(非纯白) |
| 次文本 | `#d0d6e0` | 正文 / 描述 |
| 三级文本 | `#8a8f98` | 占位 / 元数据 |
| 四级文本 | `#62666d` | 时间戳 / 禁用 |
| 品牌靛蓝 | `#5e6ad2` | CTA 背景 / 品牌标记(系统里唯一彩色) |
| 强调紫 | `#7170ff` / hover `#828fff` | 链接 / 激活态 / 选中项 |
| 状态绿 | `#27a644` / `#10b981` | 仅状态指示 |
| 半透明白边 | `rgba(255,255,255,0.05)` / `(0.08)` | 默认 / 标准描边 |
| 实色暗边 | `#23252a` / `#34343a` / `#3e3e44` | 强分隔时 |

**用色分配**:整站近乎无彩色,靛蓝/强调紫**只出现在 CTA、激活态、选中项**;状态绿只做状态,不做装饰。

## 3. 排版规则

- 字族:`Inter Variable`(回退 SF Pro Display / system-ui);`Berkeley Mono`(回退 ui-monospace / SF Mono / Menlo)专供代码与技术标签
- **OpenType 全局开 `"cv01", "ss03"`**——这不是装饰,是把通用 Inter 变成 Linear 的字形身份;不开就别称 Linear 风
- **签名字重 510**(介于 400/500 之间,微妙强调);三档体系 400(阅读)/ 510(UI 与强调)/ 590(强强调);**不用 700**
- 字距随字号收紧(显示级四元组):72px/510/1.00/-1.584px · 64px/510/1.00/-1.408px · 48px/510/1.00/-1.056px · 32px/400/1.13/-0.704px · 20px/590/1.33/-0.24px;24px 以下趋近 normal

## 4. 组件样式

| 组件 | 值 |
| ---- | -- |
| Ghost 按钮(默认) | 背景 `rgba(255,255,255,0.02)` · 文字 `#e2e4e7` · 圆角 6px · 边 `1px solid rgb(36,40,44)` |
| 主品牌按钮 | 背景 `#5e6ad2` · 文字 `#ffffff` · padding 8px 16px · 圆角 6px · hover 漂移至 `#828fff` |

| 胶囊 | 透明底 · 文字 `#d0d6e0` · 圆角 9999px · 边 `1px solid rgb(35,37,42)` |

## 5. 布局原则

- 基数 8px;节奏以 8/16/24/32 为主(7px/11px 是光学对齐的微调值,不可当节奏)
- 内容最大宽约 1200px;hero 居中单列 + 大纵向留白
- **黑暗即留白**:近黑背景本身是 whitespace;区块之间靠 80px+ 纵向间距分隔,不用可见分割线
- **压缩标题、舒展四周**:72px/-1.584px 的密集标题坐在大暗底上,张力来自"文字密、空间广"的对比

## 6. 深度与海拔

| 层 | 处理 | 用途 |
| -- | ---- | ---- |
| L0 平 | 无阴影,`#010102` 底 | 页面底 |
| L1 微 | `rgba(0,0,0,0.03) 0px 1.2px 0px` | 工具栏按钮 |
| L2 表面 | `rgba(255,255,255,0.05)` 底 + 半透明白边 | 卡片 / 输入框 |
| L2b 内凹 | `rgba(0,0,0,0.2) 0px 0px 12px 0px inset` | 内凹面板 |
| L3 环 | `rgba(0,0,0,0.2) 0px 0px 0px 1px` | 边作阴影(ring) |
| L4 抬高 | `rgba(0,0,0,0.4) 0px 2px 4px` | 浮层 / 下拉 |
| L5 对话框 | 多层栈:`rgba(0,0,0,0) 0px 8px 2px, rgba(0,0,0,0.01) 0px 5px 2px, rgba(0,0,0,0.04) 0px 3px 2px, rgba(0,0,0,0.07) 0px 1px 1px, rgba(0,0,0,0.08) 0px 0px 1px` | 弹出 / 命令面板 / 模态 |

**暗面阴影哲学**:黑对黑几乎不可见——Linear 用半透明白边做主要深度信号,海拔靠背景白透明度阶梯(`0.02 → 0.04 → 0.05`)表达,而不是阴影浓度。

## 7. Do's and Don'ts

**Do**:全局 `"cv01", "ss03"` · 510 作默认强调 · 显示级负字距 · 近黑底(`#08090a` 营销 / `#0f1011` 面板 / `#191a1b` 抬升) · 半透明白边替代实色暗边 · 按钮背景近零透明度(0.02-0.05) · 靛蓝只留给 CTA 与交互 · 主文本用 `#f7f8f8` 不用纯白
**Don't**:不用纯白当主文本 · 不用实色按钮背景 · 不把靛蓝做装饰 · 显示级不用正字距 · 不用不透明实色暗边 · 不跳过 OpenType features(跳过就是通用 Inter)· 不用 700 字重(上限 590)· 不引入暖色(冷灰 + 蓝紫唯一彩色)· 暗面不用投影表达海拔,用亮度阶梯

## 8. 响应式

- 断点:600 / 640 / 768 / 1024 / 1280px;导航 768px 折为汉堡
- hero 显示字号 72 → 48 → 32,字距同比例收紧;feature 卡 3 列 → 2 列 → 单列
- 区块纵向间距 80px+ → 移动端 48px;截图保持边与圆角处理

## 9. Agent Prompt Guide

- 快速取色:CTA `#5e6ad2` · 页面底 `#08090a` · 面板 `#0f1011` · 表面 `#191a1b` · 标题 `#f7f8f8` · 正文 `#d0d6e0` · 弱化 `#8a8f98` · 默认边 `rgba(255,255,255,0.08)` · 强调紫 `#7170ff`
- 例:"在 `#08090a` 上做 hero:标题 48px Inter Variable 510,行高 1.00,字距 -1.056px,色 `#f7f8f8`,`font-feature-settings: 'cv01','ss03'`;副标 18px/400/1.60 `#8a8f98`;主按钮 `#5e6ad2`/6px/8px 16px + 幽灵按钮 `rgba(255,255,255,0.02)` 底 + `1px solid rgba(255,255,255,0.08)`"
- 迭代纪律:① 所有 Inter 文本开 `"cv01","ss03"`,不可协商 ② 字距随字号缩放(72px→-1.584px、48px→-1.056px、32px→-0.704px、16px 以下 normal)③ 只有三档字重 400/510/590 ④ 海拔用背景透明度阶梯 0.02→0.04→0.05 ⑤ 靛蓝是唯一彩色,其余全灰阶 ⑥ 暗底边框永远半透明白 ⑦ 代码与技术标签用 Berkeley Mono
