# 设计系统:Framer

## 1. 视觉主题与氛围

Framer 的官网是一块电影感、痴迷工具的黑画布,散发出一个由崇拜手艺的设计师所做的设计工具才有的自信。整个体验浸在纯黑里——不是暖炭灰,不是温吞的深灰,而是绝对的虚空(`#000000`),让每个元素、每张截图、每处排版巧思都像浮在深空。这个网站把自家产品 UI 当 hero 艺术,把全保真截图和交互 demo 直接嵌进叙事流。

排版是签名动作:GT Walsheim 配激进收紧的字距(110px 显示级文字上到 -5.5px),造出被压缩、充满动势、几乎上紧发条的标题——像受压的词语随时可能撑开。正文切到 Inter 毫无缝隙,大范围使用 OpenType 特性(`cv01`、`cv05`、`cv09`、`cv11`、`ss03`、`ss07`),让小字也有定制般的精细感。Framer Blue(`#0099ff`)用得克制但果断——作链接色、边框强调、微弱环状阴影——在这片无暖意的黑上拉出一条冷电般的贯穿线。

整体效果是给网页设计师开的夜店:黑、精确、诱人,毫不掩饰地把产品推到台前。每个区块都为展示工具能做什么而存在,网站本身即概念验证。

**关键特征:**
- 纯黑(`#000000`)虚空画布——绝对的黑,不带暖调,不带灰调
- GT Walsheim 显示字体配极端负字距(110px 上 -5.5px)
- Framer Blue(`#0099ff`)作唯一强调色——冷、电、精确
- 药丸形按钮(40px–100px 圆角)——交互元素不用尖角
- 产品截图即 hero 艺术——工具本身就是营销
- 深底上 `rgba(255, 255, 255, 0.1)` 的磨砂玻璃按钮变体
- Inter 上大范围使用 OpenType 特性,做精细微排版

## 2. 色板与角色

### 主色
- **纯黑**(`#000000`):主背景,定义 Framer 暗色原生身份的虚空画布
- **纯白**(`#ffffff`):深底上的主文本色,强调底上的按钮文字
- **Framer Blue**(`#0099ff`):主强调色——链接、边框、环状阴影、交互高亮

### 次级与强调
- **柔银**(`#a6a6a6`):次文本、弱化标签、深底上变暗的描述
- **近黑**(`#090909`):抬高的深色表面,作微弱深度分隔的阴影环色

### 表面与背景
- **虚空黑**(`#000000`):页面背景,主画布
- **磨砂白**(`rgba(255, 255, 255, 0.1)`):半透明按钮背景,深底上的玻璃效果表面
- **微弱白**(`rgba(255, 255, 255, 0.5)`):稍更不透明的磨砂元素,用于悬浮态

### 中性色与文本
- **纯白**(`#ffffff`):标题文字、高强调正文
- **柔银**(`#a6a6a6`):正文、描述、次要信息
- **幽灵白**(`rgba(255, 255, 255, 0.6)`):三级文字、深底上的占位符

### 语义与强调
- **Framer Blue**(`#0099ff`):链接、交互边框、焦点环
- **蓝色辉光**(`rgba(0, 153, 255, 0.15)`):焦点环阴影,交互元素周围的微弱蓝色光晕
- **默认链接蓝**(`#0000ee`):标准浏览器链接色(仅在内容区少量使用)

### 渐变系统
- 没有显眼的渐变用法——Framer 靠纯平黑表面,偶尔用蓝色染色辉光表达深度
- 产品截图后方用极低透明度的 Framer Blue 做微弱径向辉光

## 3. 排版规则

### 字族
- **显示**:`GT Walsheim Framer Medium` / `GT Walsheim Medium`——自研几何无衬线,字重 500。回退:`GT Walsheim Framer Medium Placeholder`、system sans-serif
- **正文/UI**:`Inter Variable` / `Inter`——可变无衬线,大量 OpenType 特性。回退:`Inter Placeholder`、`-apple-system`、`system-ui`
- **强调**:`Mona Sans`——GitHub 的开源字体,以极浅字重(100)用于部分元素
- **等宽**:`Azeret Mono`——配对的等宽字体,供代码与技术标签
- **圆体**:`Open Runde`——小型圆体配套字体,供微型标签

### 原则
- **压缩即性格**:GT Walsheim 的极端负字距(110px 上 -5.5px)是定义性的排版手势——标题像上紧发条、急促、几乎喘不过气
- **OpenType 极繁**:Inter 同时开 6 个以上 OpenType 特性(`cv01`、`cv05`、`cv09`、`cv11`、`ss03`、`ss07`),连正文尺寸也有微妙的定制感
- **显示级字重克制**:GT Walsheim 一律用字重 500(中等)——从不粗体,从不常规。造出自信但不具攻击性的显示语气
- **极紧行高**:显示级文字行高 0.85,意味着字母在纵向上几乎重叠——有意的密度,在一臂之外阅读时更受用

## 4. 组件样式

### 按钮
- **磨砂药丸**:`rgba(255, 255, 255, 0.1)` 背景,黑字(`#000000`),药丸形(40px 圆角)。深底上的玻璃效果按钮——半透明、环境化、微弱
- **实白药丸**:`rgb(255, 255, 255)` 背景,黑字(`#000000`),全药丸形(100px 圆角),padding `10px 15px`。主 CTA——干净、在深底上高对比、无法忽视
- **幽灵**:无可见背景,白字,只靠文字样式。悬浮时露出微弱磨砂背景
- **过渡**:缩放动画(矩阵变换,0.85 缩放系数),透明度过渡做显影效果

### 卡片与容器
- **深色表面卡**:黑或近黑(`#090909`)背景,`rgba(0, 153, 255, 0.15) 0px 0px 0px 1px` 蓝色环状阴影作边框,圆角(10px–15px)
- **抬高卡**:多层阴影——`rgba(255, 255, 255, 0.1) 0px 0.5px 0px 0.5px`(微弱顶部高光)+ `rgba(0, 0, 0, 0.25) 0px 10px 30px`(深环境阴影)
- **产品截图**:全宽或深色容器内加内距,软件 UI 预览用 8px–12px 圆角
- **悬浮态**:Framer Blue 环状阴影轻微增强辉光,或磨砂表面亮度偏移

### 输入与表单
- 营销站上表单存在感极低
- 输入框沿用暗色主题:深背景、微弱边框、白字
- 聚焦态:Framer Blue(`#0099ff`)环状边框,`1px solid #0099ff`
- 占位文字 `rgba(255, 255, 255, 0.4)`

### 导航
- **深色浮动导航栏**:黑背景配磨砂玻璃效果,白色文字链接
- **导航链接**:Inter 15px,字重 400,白字配悬浮态轻微透明度变化
- **CTA 按钮**:药丸形,白或磨砂,置于导航右端
- **移动端**:折叠为汉堡菜单,保持暗色主题
- **吸顶行为**:滚动时导航固定顶部

### 图片处理
- **产品截图即 hero 艺术**:全宽嵌入 UI 截图,圆角(8px–12px)
- **深底叠深底构图**:截图置于黑背景上,配微弱阴影做深度分隔
- **16:9 与自定义宽高比**:产品 demo 填满其容器
- **无装饰性影像**:所有图片都有功能——展示工具、产出或流程

### 信任与社会证明
- 客户 logo 与推荐语在深底上呈弱化灰
- 装饰极简——产品截图本身就是信任信号

## 5. 布局原则

### 间距系统
- **基数**:8px
- **刻度**:1px, 2px, 3px, 4px, 5px, 6px, 8px, 10px, 12px, 15px, 20px, 30px, 35px
- **区块内距**:大纵向间距(区块之间 80px–120px)
- **卡片内距**:内部 15px–30px
- **组件间隙**:相关元素之间 8px–20px

### 网格与容器
- **最大宽**:约 1200px 容器,居中
- **列模式**:全宽 hero、两列功能区、单列产品展示
- **非对称布局**:功能区常把文本(40%)与截图(60%)配对

### 留白哲学
- **在黑暗中呼吸**:区块间纵向间距宽裕——黑背景让留白呈现为虚空,在内容块之间造出戏剧性停顿
- **内密外疏**:单个组件编排紧密(紧行高、压缩文字),却浮在宽裕的周围空间里
- **产品优先的密度**:截图区允许密而信息丰富,与稀疏的营销文字形成对比

### 圆角刻度
- **1px**:微型元素,几乎方正的精确边
- **5px–7px**:小 UI 元素、图片缩略图——轻微柔化
- **8px**:标准组件圆角——代码块、按钮、交互元素
- **10px–12px**:卡片、产品截图——舒适圆润
- **15px–20px**:大容器、特色卡——宽裕圆润
- **30px–40px**:导航药丸、分页——明显圆润
- **100px**:全药丸形——主 CTA、标签元素

## 6. 深度与海拔

| 层 | 处理 | 用途 |
|-------|-----------|-----|
| 平(Level 0) | 无阴影,纯黑表面 | 页面背景、空白区 |
| 环(Level 1) | `rgba(0, 153, 255, 0.15) 0px 0px 0px 1px` | 卡片边框、交互元素轮廓——Framer Blue 辉光环 |
| 围合(Level 2) | `rgb(9, 9, 9) 0px 0px 0px 2px` | 近黑环,在深底上做微弱围合 |
| 浮动(Level 3) | `rgba(255, 255, 255, 0.1) 0px 0.5px 0px 0.5px, rgba(0, 0, 0, 0.25) 0px 10px 30px` | 抬高卡、浮动元素——微弱白色顶边高光 + 深环境阴影 |

### 阴影哲学
Framer 的海拔系统与传统亮色主题设计相反。它不在浅底上用深阴影,而是用:
- **蓝色染色环状阴影**,极低透明度(0.15)做围合——一个给每个带边框元素微染品牌的签名动作
- **白色边缘高光**(0.5px)打在抬高元素的顶边——模拟光打在顶面
- **深环境阴影**给真正浮动的元素——`rgba(0, 0, 0, 0.25)` 配大扩散(30px)

### 装饰性深度
- **蓝色辉光晕**:关键交互区后方用微弱 Framer Blue(`#0099ff`)径向渐变
- **无背景模糊/玻璃拟态**:虽有磨砂按钮效果,但没有重度玻璃模糊——半透明靠简单的 rgba 透明度实现

## 7. Do's and Don'ts

### Do
- 用纯黑(`#000000`)作主背景——不是深灰,不是炭灰
- 在 GT Walsheim 显示级文字上施加极端负字距(-3px 至 -5.5px)
- 所有按钮保持药丸形(40px+ 圆角)——从不用方正或微圆角按钮
- Framer Blue(`#0099ff`)只用于交互强调——链接、边框、聚焦态
- 深底上的磨砂玻璃表面用 `rgba(255, 255, 255, 0.1)`
- GT Walsheim 只保持字重 500——中字重就是品牌
- Inter 文字上用足 OpenType 特性(cv01, cv05, cv09, cv11, ss03, ss07)
- 让产品截图当视觉中心——工具自我营销
- 卡片围合用蓝色环状阴影(`rgba(0, 153, 255, 0.15) 0px 0px 0px 1px`)

### Don't
- 用暖调深色背景(不要 `#1a1a1a`、`#2d2d2d` 或偏褐的黑)
- 给 GT Walsheim 显示级文字加粗(700+)——只用中等 500
- 引入 Framer Blue 之外的其他强调色——这是单强调色系统
- 在非交互元素上用大圆角(卡片用 10px–15px,只有按钮才给 40px+)
- 加装饰性影像、插画或图标——产品本身就是插画
- 标题用正字距——一切都压缩、负字距
- 使用重投影——深度靠微弱环与极简环境阴影传达
- 在内容区后面放浅色/白背景——虚空是神圣的
- 用衬线或显示级字重字体——系统只用几何无衬线

## 8. 响应式

### 断点
| 名称 | 宽度 | 关键变化 |
|------|-------|-------------|
| 移动 | <809px | 单列、功能区纵向堆叠、hero 文字缩小(62px→40px)、汉堡导航 |
| 平板 | 809px–1199px | 功能区开始两列,导航链接部分可见,截图缩放变小 |
| 桌面 | >1199px | 完整布局,导航展开含全部链接 + CTA,110px 显示级 hero,功能并排 |

### 触控目标
- 药丸按钮:最小 40px 高配 10px 纵向内距——超过 44px 的 WCAG 下限
- 导航链接:15px 文字配宽裕内距,便于触控
- 移动端 CTA 按钮:移动端全宽药丸,方便拇指够到

### 折叠策略
- **导航**:完整横向导航 → 移动断点折为汉堡菜单
- **Hero 文字**:110px 显示级 → 85px → 62px → 约 40px,跨断点按比例保持极端负字距
- **功能区**:并排(文字 + 截图)→ 移动端纵向堆叠
- **产品截图**:在容器内响应式缩放,保持宽高比
- **区块间距**:按比例递减——桌面 120px → 移动 60px

### 图片行为
- 产品截图响应式,在容器边界内缩放
- 无艺术指导变化——跨断点同一裁切
- 深背景确保截图在任何尺寸都保持视觉冲击
- 截图随用户滚动进入视野而懒加载

### 迭代指南
精修用本设计系统生成的现有界面时:
1. 一次只专注一个组件——深画布让每个元素都珍贵
2. 永远核对 GT Walsheim 标题的字距——极端负字距不容让步
3. 检查 Framer Blue 只出现在交互元素上——绝不作装饰背景,也不作非链接的文字色
4. 确保所有按钮都是药丸形——任何方角都会立刻破坏 Framer 美学
5. 测试磨砂玻璃表面时核对是否正好是 `rgba(255, 255, 255, 0.1)`——太不透明像 bug,太透明会消失
