# 设计系统:IBM

## 1. 视觉主题与氛围

IBM 的网站建立在 Carbon Design System 之上,是企业权威的数字化身——这套设计语言组织得如此有条理,读起来像一份渲染成网页的工程规格书。页面运行在鲜明的二元性上:亮白(`#ffffff`)画布配近黑(`#161616`)文字,点缀唯一一个毫不动摇的强调色——IBM Blue 60(`#0f62fe`)。这不是俏皮的科技创业极简主义,而是把企业级精密蒸馏进像素。每个元素都存在于 Carbon 严格的 2x 网格里,每个颜色都映射到语义 token,每个间距值都对齐到 8px 基数。

IBM Plex 字族是系统的骨架。显示级大标题用 300 细字重的 IBM Plex Sans,在大字号下呈现出意外通透、近乎纤巧的质感——这是对 IBM 企业分量的刻意反衬。正文尺度上,400 常规字重,14px 说明文字配 0.16px 字距,引入了那种一丝不苟的微字距,让 Carbon 的文字感觉像被工程化而非被设计过。IBM Plex Mono 服务代码、数据与技术标签,与很少露面的 IBM Plex Serif 一起补全了字族三件套。

除"单色加一蓝"之外,IBM 视觉身份的定义点在于对 Carbon 组件 token 系统的依赖。每个交互状态都映射到以 `--cds-`为前缀的 CSS 自定义属性。按钮没有硬编码颜色,它们引用 `--cds-button-primary`、`--cds-button-primary-hover`、`--cds-button-primary-active`。这种 token 化架构意味着整个视觉层只是深层系统化地基上的一层薄皮——相当于设计界的一份类型良好的 API。

**关键特征:**
- 显示级用 IBM Plex Sans 字重 300(Light)——靠排版克制表达企业分量
- 代码与技术内容用 IBM Plex Mono,小字号下统一 0.16px 字距
- 唯一强调色:IBM Blue 60(`#0f62fe`)——每个交互元素、每个 CTA、每条链接
- Carbon token 系统(`--cds-*`)驱动全部语义色,可在变量层面切换主题
- 8px 间距网格严格遵循——没有随意值,一切都对齐
- `#f4f4f4` Gray 10 表面上的扁平无边框卡片——靠背景色分层而非阴影表达深度
- 底部边框输入框(不是盒状)——Carbon 签名表单模式
- 主按钮圆角 0px——不掩饰的矩形,不做柔化

## 2. 色板与角色

### 主色
- **IBM Blue 60**(`#0f62fe`):唯一的交互色。主按钮、链接、焦点态、激活指示。这是核心 UI 色板里唯一的彩色色相。
- **White**(`#ffffff`):页面背景、卡片表面、蓝底按钮文字,`--cds-background`。
- **Gray 100**(`#161616`):主文本、标题、暗面背景、导航栏、footer。`--cds-text-primary`。

### 中性色阶(Gray 家族)

- **Gray 90**(`#262626`):次级暗面、暗面 hover 态。
- **Gray 80**(`#393939`):三级暗色、激活态。
- **Gray 70**(`#525252`):次级文本、辅助文字、描述。`--cds-text-secondary`。
- **Gray 60**(`#6f6f6f`):占位文本、禁用文本。
- **Gray 50**(`#8d8d8d`):禁用图标、弱化标签。

- **Gray 10**(`#f4f4f4`):次级表面背景、卡片填充、交替行。`--cds-layer-01`。
- **Gray 10 Hover**(`#e8e8e8`):Gray 10 表面的 hover 态。

### 交互
- **Blue 60**(`#0f62fe`):主交互——按钮、链接、焦点。`--cds-link-primary`、`--cds-button-primary`。

### 原则
- **显示级用细字重**:Carbon 的表达性字型在 42px+ 用字重 300(Light)。这制造出一种独特张力——内容以企业权威发声,而字形以排版的轻盈耳语。
- **小字号微字距**:14px 配 0.16px 字距,12px 配 0.32px。这些看似可忽略的值是 Carbon 在紧凑尺度的可读性秘密武器——它们刚好把紧收的 IBM Plex 字形打开一点。
- **三种功能字重**:300(显示/表达)、400(正文/阅读)、600(强调/UI 标签)。字重 700 被刻意排除在生产字阶之外。
- **功能性 vs 表达性**:功能性字型用更紧的行高(1.29),适合密集 UI。表达性字型更舒展(1.40-1.50),适合营销与编辑内容。

## 5. 布局原则

### 间距系统
- 基数:8px
- 组件间距刻度:2px, 4px, 8px, 12px, 16px, 24px, 32px, 40px, 48px
- 布局间距刻度:16px, 24px, 32px, 48px, 64px, 80px, 96px, 160px
- 最小单位:8px(最小可用间距)
- 组件内边距:通常 16px
- 卡片/瓦片间隙:1px(发丝线)或 16px(标准)

### 网格与容器
- 16 列网格
- 内容最大宽:1584px(最大断点)
- 列槽:32px(移动端 16px)
- 外边距:16px(移动端)、32px(平板及以上)
- 内容通常跨 8-12 列,以保持可读的行长
- 全出血区块与收束内容交替

### 留白哲学
- **功能性密度**:Carbon 偏爱生产性密度而非扩张式留白。相比消费类设计系统,区块排得更紧——这反映 IBM 的企业基因。
- **背景色分区**:IBM 不在区块间堆巨大内边距,而用交替背景色(白 → gray 10 → 白)在最小纵向空间里制造视觉分隔。
- **统一 48px 节奏**:主要区块过渡用 48px 纵向间距。hero 区可用 80px–96px。

### 圆角刻度
- **0px**:主按钮、输入框、瓦片、卡片——主导处理。Carbon 根本上是矩形的。
- **2px**:偶尔用于小交互元素(标签)
- **24px**:标签/标号(药丸形——唯一圆角例外)
- **50%**:头像圆、图标容器

## 6. 深度与海拔

| 层 | 处理 | 用途 |
|-------|-----------|-----|
| 平(第 0 层) | 无阴影,`#ffffff` 背景 | 默认页面表面 |
| 第 01 层 | 无阴影,`#f4f4f4` 背景 | 卡片、瓦片、交替区块 |
| 第 02 层 | 无阴影,`#e0e0e0` 背景 | 第 01 层内的抬升面板 |
| 抬升 | `0 2px 6px rgba(0,0,0,0.3)` | 下拉、tooltip、溢出菜单 |
| 覆盖层 | `0 2px 6px rgba(0,0,0,0.3)` + 暗色遮罩 | 模态对话框、侧面板 |
| 焦点 | `2px solid #0f62fe` 内嵌 + `1px solid #ffffff` | 键盘焦点环 |
| 底边 | 底缘 `2px solid #161616` | 激活输入框、激活标签指示 |

**阴影哲学**:Carbon 刻意回避阴影。IBM 主要靠背景色分层表达深度——把逐渐变深的灰表面叠起来,而不是加 box-shadow。这造就扁平、印刷感的美学,层级通过色彩明度而非模拟光线传达。阴影只保留给真正浮于内容之上的元素(下拉、tooltip、模态)。这种克制让少见的阴影有了真正的影响力——在 Carbon 里,当某物浮起来,它是有分量的。

## 7. Do's and Don'ts

### Do
- 显示级(42px+)用 IBM Plex Sans 字重 300——那份轻盈是有意的
- 14px 正文配 0.16px 字距,12px 说明配 0.32px
- 按钮、输入框、卡片、瓦片用 0px 圆角——矩形就是系统
- 实现时引用 `--cds-*` token 名(如 `--cds-button-primary`、`--cds-text-primary`)
- 用背景色分层(白 → gray 10 → gray 20)而非阴影表达深度
- 输入框指示用底边(不是盒状)
- 保持 48px 默认按钮高度与非对称内边距,给图标留位
- 把 Blue 60(`#0f62fe`)当唯一强调——一种蓝统治全部

### Don't
- 不要把按钮圆角化——0px 圆角是 Carbon 身份
- 不要在卡片或瓦片上用阴影——扁平才是重点
- 不要引入额外强调色——IBM 的系统是单色加一蓝
- 不要用字重 700(Bold)——字阶止于 600(Semibold)
- 不要给显示级文字加字距——字距只用于 14px 及以下
- 不要用全边框把输入框盒起来——Carbon 输入框只用底边
- 不要用渐变背景——IBM 的表面是扁平实色
- 不要偏离 8px 间距网格——每个值都应能被 8 整除(2px 与 4px 用于微调)

## 8. 响应式

### 断点
| 名称 | 宽度 | 关键变化 |
|------|-------|-------------|
| 小(sm) | 320px | 单列、汉堡导航、16px 外边距 |
| 中(md) | 672px | 2 列网格开始、内容扩展 |
| 大(lg) | 1056px | 完整导航可见、3-4 列网格 |
| 超大(xlg) | 1312px | 最大内容密度、宽布局 |
| 最大 | 1584px | 最大内容宽,居中带外边距 |

### 触控目标
- 按钮高度:默认 48px,最小 40px(紧凑)
- 导航链接:48px 行高便于触控
- 输入框高度:默认 40px,大号 48px
- 图标按钮:48px 方形触控目标
- 移动端菜单项:全宽 48px 行

### 折叠策略
- Hero:视口变窄时标题 60px → 42px → 32px
- 导航:全宽水平报头 → 汉堡配滑出面板
- 网格:4 列 → 2 列 → 单列
- 瓦片/卡片:水平网格 → 纵向堆叠
- 图片:保持宽高比,最大宽 100%
- Footer:多列链接组 → 单列堆叠
- 区块内边距:48px → 32px → 16px

### 图片行为
- 响应式图片用 `max-width: 100%`
- 产品插画按比例缩放
- hero 图片可从并排转为下方堆叠
- 数据可视化保持宽高比,移动端横向滚动

### 迭代指南
1. 按钮、输入框、卡片永远用 0px 圆角——在 Carbon 里这点不可协商
2. 字距只在小字号:14px 配 0.16px,12px 配 0.32px——绝不用在显示级文字
3. 三种字重:300(显示)、400(正文)、600(强调)——没有 bold
4. Blue 60 是唯一强调色——不要引入次级强调色相
5. 深度来自背景色分层(白 → #f4f4f4 → #e0e0e0),不是阴影
6. 输入框只有底边,永不完整盒状
7. token 命名用 `--cds-` 前缀以保持 Carbon 兼容
8. 48px 是通用的交互元素高度
