# Soft UI Evolution

## 1. 视觉主题与氛围

Soft UI Evolution 是为通用界面提供的 UI 风格参照,融合演进式软 UI、更好的对比、现代审美、细微深度、无障碍导向、改进的阴影、混合式。视觉方向由改进的阴影(比扁平柔、比新拟态清晰)、现代(200-300ms)、焦点可见、WCAG AA/AAA 塑造。

用于现代企业应用、SaaS 平台、健康/康养、现代商业工具、专业场景、混合式。避免用于极端极简、性能关键的场景、没有现代操作系统的系统。

**关键特征:**
- 主色板:对比改进的粉彩:柔蓝 #87CEEB、柔粉 #FFB6C1、柔绿 #90EE90,层级更清晰
- 次色板:更好的配色组合、无障碍次级色、对比改进的辅助色、现代强调色
- 效果:改进的阴影(比扁平柔、比新拟态清晰)、现代(200-300ms)、焦点可见、WCAG AA/AAA
- 无障碍:✓ 达 WCAG AA+;性能:⚡ 优秀;暗色模式:✓ 完整。
- 最适用于:现代企业应用、SaaS 平台、健康/康养、现代商业工具、专业场景、混合式
- 避免用于:极端极简、性能关键的场景、没有现代操作系统的系统
