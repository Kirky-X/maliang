# Swiss Modernism 2.0

## 1. 视觉主题与氛围

Swiss Modernism 2.0 是为通用界面提供的 UI 风格参照,融合网格系统、Helvetica、模块化、非对称、国际主义风格、理性、干净、数学化间距。视觉方向由 display: grid、grid-template-columns: repeat(12 1fr)、gap: 1rem、数学比例、清晰层级塑造。

用于企业站点、建筑、编辑出版、SaaS、博物馆、专业服务、文档。避免用于玩趣品牌、儿童站点、娱乐、游戏、情感叙事。

**关键特征:**
- 主色板:#000000、#FFFFFF、#F5F5F5,只用一个鲜亮强调色
- 次色板:次级元素极少,强调只用于突出重点,不用渐变
- 效果:display: grid、grid-template-columns: repeat(12 1fr)、gap: 1rem、数学比例、清晰层级
- 无障碍:✓ WCAG AAA;性能:⚡ 优秀;暗色模式:✓ 完整。
- 最适用于:企业站点、建筑、编辑出版、SaaS、博物馆、专业服务、文档
- 避免用于:玩趣品牌、儿童站点、娱乐、游戏、情感叙事
