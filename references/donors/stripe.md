# Stripe —— 金融精致(轻字重 + 蓝调阴影)

## 1. 视觉主题与氛围

"由世界级字体铸造厂重新设计的金融机构":技术感与奢华感并存。白画布 + 深海军蓝标题 + 饱和紫罗兰强调;**签名是浅字重大标题**(300)——在别人用 600-700 喊叫的地方,Stripe 用轻盈表达"自信到不需要重量"。真差异化在**蓝调染色阴影**:海拔也带品牌氛围。

## 2. 色板与角色

| 角色 | 值 | 用途 |
| ---- | -- | ---- |
| Stripe 紫 | `#533afd` | 主品牌 / CTA 底 / 链接 / 交互强调 |
| 紫 hover / 深 | `#4434d4` / `#2e2b8c` | hover 态 / 图标 hover |
| 深海军蓝 | `#061b31` | 标题色(**不用黑**:微暖微深) |
| 标签蓝 | `#273951` | 表单标签 / 次级标题 |
| 正文石板灰 | `#64748d` | 正文 / 描述 / 占位 |
| 品牌暗 | `#1c1e54` | 暗色品牌区块 / footer |

## 3. 排版规则

- 字族:`sohne-var`(回退 SF Pro Display);`SourceCodePro`(回退 SFMono-Regular)供代码
- **OpenType 全局开 `"ss01"`**——它改字形(`a`/`g`/`l` 交替形),就是品牌;表格与金融数字开 `"tnum"`
- **签名字重 300**:大标题与正文都用浅字重;400 只给按钮 / 链接 / 导航;**主字族不用 700**
- 字距四元组:56px/300/1.03/-1.4px · 48px/300/1.15/-0.96px · 32px/300/1.10/-0.64px · 26px/300/1.12/-0.26px · 16px 及以下 normal
- 字号档细密(10/12/13/14/16/18/22/26/32/48/56),金融界面小字档位齐全

## 4. 组件样式

| 组件 | 值 |
| ---- | -- |
| 主按钮 | 底 `#533afd` · 字 `#ffffff` · padding 8px 16px · 圆角 4px · 16px/400 `"ss01"` · hover `#4434d4` |
| 幽灵按钮 | 透明底 · 字 `#533afd` · 边 `1px solid #b9b9f9` · 圆角 4px · hover 底 `rgba(83,58,253,0.05)` |

| 成功徽章 | 底 `rgba(21,190,83,0.2)` · 字 `#108c3d` · 边 `1px solid rgba(21,190,83,0.4)` · 10px/300 |

| 装饰 | 虚线段 `1px dashed #362baa`;hero 用 ruby→magenta 渐变 |

## 5. 布局原则

- 基数 8px;小端密集(4-12px 每 2px 一档),反映金融界面的精密取向
- 内容最大宽约 1080px;hero 居中单列
- **精密留白**(不是极简式空旷):每个间隙都是有意的排版选择;数据区紧、chrome 区松——"美丽画框里的整齐表格"
- 区块节奏:白区与暗品牌区(`#1c1e54`)交替,形成明暗节拍而不引入任意色

## 6. 深度与海拔

| 层 | 处理 | 用途 |
| -- | ---- | ---- |
| L0 平 | 无阴影 | 页面底 |
| L1 环境 | `rgba(23,23,23,0.06) 0px 3px 6px` | 卡片微抬 / hover 提示 |
| L2 标准 | `rgba(23,23,23,0.08) 0px 15px 35px` | 标准卡 / 内容面板 |
| L3 抬高 | `rgba(50,50,93,0.25) 0px 30px 45px -30px, rgba(0,0,0,0.1) 0px 18px 36px -18px` | 特色卡 / 下拉 / 浮层 |
| L4 深 | `rgba(3,3,39,0.25) 0px 14px 21px -14px, rgba(0,0,0,0.1) 0px 8px 17px -8px` | 模态 / 浮动面板 |

**阴影哲学**:颜色深度——主阴影色 `rgba(50,50,93,0.25)` 是蓝灰,呼应海军蓝配色,"阴影也带品牌氛围";远层蓝调 + 近层中性黑形成视差式深度;负扩散(-30px/-18px)让阴影保持垂直、不横向溢出。

## 7. Do's and Don'ts

**Do**:sohne-var 全局 `"ss01"` · 标题正文用 300 · 抬高元素用蓝调阴影 · 标题用 `#061b31` 深海军蓝 · 圆角守在 4-8px · 表格数字开 `"tnum"` · 阴影"远蓝近黑"双层 · 紫 `#533afd` 作唯一交互/CTA 色
**Don't**:标题 600-700 · 大圆角(12px+)/pill 上卡片按钮 · 中性灰阴影(必须蓝调)· 任何文本跳过 `"ss01"` · 标题用纯黑 · 交互元素用暖色(ruby/magenta 只做装饰渐变)· 显示级正字距 · ruby/magenta 用在按钮或链接

## 8. 响应式

- 断点:<640 / 640-1024 / 1024-1280 / >1280px
- hero 56 → 48 → 32px,维持 300 字重;feature 卡 3 → 2 → 1 列
- 金融数据表移动端横向滚动;区块间距 64px+ → 40px;暗品牌区保持全宽、收内边距

## 9. Agent Prompt Guide

- 快速取色:CTA `#533afd`(hover `#4434d4`)· 底 `#ffffff` · 标题 `#061b31` · 正文 `#64748d` · 标签 `#273951` · 边 `#e5edf5` · 暗区 `#1c1e54` · 装饰 `#ea2261` / `#f96bee`
- 例:"白底 hero:标题 48px sohne-var 300,行高 1.15,字距 -0.96px,色 `#061b31`,`font-feature-settings:'ss01'`;副标 18px/300/1.40 `#64748d`;紫 CTA(`#533afd`,4px 圆角,8px 16px)+ 幽灵按钮(透明底,`1px solid #b9b9f9`)"
- 迭代纪律:① 所有 sohne-var 文本开 `"ss01"` ② 300 是默认,400 只给按钮/链接/导航 ③ 阴影公式 `rgba(50,50,93,0.25) 0px Y1 B1 -S1, rgba(0,0,0,0.1) 0px Y2 B2 -S2`(远层大、近层小)④ 标题 `#061b31`、正文 `#64748d`、标签 `#273951` ⑤ 圆角 4-8px,永不 pill ⑥ 表格 / 图表数字开 `"tnum"` ⑦ 暗区用 `#1c1e54` 深靛
